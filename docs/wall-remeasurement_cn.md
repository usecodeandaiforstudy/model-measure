# 墙的重测：用机制研究指出更好的配方来测项目的墙

**为什么。** BUDGET-MECHANISM 把一道已定位墙的膨胀归因于固定学习率：在实例 C = 216、sigma = 0.5、K = 4096 上，
*只*把调度换成余弦退火，就把 12% 的保留赤字变成了负数，并把已定位的墙从"≥ 4096，无法定位"移到了 K = 512 ——
一个 ≥ 8× 的变化。本项目此前每一道墙都是用固定学习率配方定位的，所以自然的读法是"那些值是被配方夸大的上界"。
本次战役直接检验这个读法：用余弦退火重新定位各道墙，并追问那个对项目主张至关重要的问题：
**SHAPE 结论还活着，还是说它们也只是配方的产物？**

**判定：这个预期被 REFUTED，而形状被 CONFIRMED。**
- **S1（墙下降）FAILED。** 在 SCALE-C 各实例上墙是**配方稳健**的：C = 8 反而*上升*了（8 -> 32），
  而 C = 27 / 64 / 216 **不变**（128 / 512 / 512）。所以"固定学习率抬高墙"**并不**普遍 ——
  ≥ 8× 的效应特定于那一个实例（更容易的任务，sigma = 0.5，学生能在预算内收敛）。
- **S2（形状）完全活了下来**：墙依然陡峭增长然后**饱和**（顶部为 512、512），
  而松紧在 C 上依然**非单调**，序列相同（2.72 / 2.82 / 3.01 / 2.72）。只有*拟合出来的*指数变了：
  alpha = 0.890（R² = 0.870），对照第 3 轮的 1.284（R² = 0.830）。
- **S3（健全性）PASSED**：在新配方下**每个 C 都是零假排除** —— 头号规则的第四次独立确认，
  也是第一次在不同训练配方下得到的确认。

## 1. 测了什么

模式 A：SCALE-C 第 3 轮的实例（C = 8 / 27 / 64 / 216，sigma = 1.0，60 epoch，第 3 轮的 K 网格）。
**参照模型及其缓存的软目标是第 3 轮的产物，原样复用**，学生初始化种子是第 3 轮的种子，预算也是第 3 轮的预算 ——
因此与第 3 轮的唯一差别就是学习率调度（从 1e-2 到 0 的余弦，而不是固定的 1e-2）。模式 B：cp3 协议（C = 64，
sigma = 1.0，参照 VQ(256)），其记录的墙是 96。

| 实例 | 墙，固定学习率（记录值） | 墙，余弦 | 变化 |
| --- | --- | --- | --- |
| C = 8 | 8 | **32** | **上升（更差）** |
| C = 27 | 128 | 128 | 无 |
| C = 64 | 512 | 512 | 无 |
| C = 216 | 512 | 512 | 无 |
| cp3（C = 64，`K_t` = 256） | 96 | **96** | 无 —— **精确复现** |

cp3 这一行值得单独一句话：从头重跑那个协议，**精确**复现了原始战役记录的墙，这是对那次战役数字在不同调度下的
独立验证。

## 2. 预期为什么失败（诚实的机制）

余弦退火缩短了运行末期的*有效*学习，这只有在运行长到足以收敛时才有回报。在 BUDGET-MECHANISM 实例上
（sigma = 0.5）60 epoch 足够，退火把 12% 的赤字变成了 **-0.8%**；在 SCALE-C 各实例上（sigma = 1.0，更难的任务）
同样的 60 epoch 预算*不*够，退火反而**欠训练**：在 C = 8，K = 8 的学生赤字从
0.08 升到 0.24，这正是把已定位的墙从 8 推到 32 的原因。

所以配方效应是**任务难度、预算与调度的相互作用**，不是免费的改进：

> **正确的表述不是"余弦更好"，也不是"固定学习率抬高墙"，而是：衰减学习率的调度需要一个长到足以收敛的
> 预算；有这个预算时它能打平保留赤字（实测：0.12 -> -0.008），没有时它就会欠训练，并可能把一道墙推向
> *错误*的方向（实测：8 -> 32）。**

那也意味着早先笔记里的那句话 —— "本笔记之前本项目定位的每一道墙都是被配方夸大的上界" —— 被**撤回**：
在 SCALE-C 各实例上这些值是配方稳健的，而配方改变的是*调度与预算的匹配*，不是墙的高度。

## 3. 什么成立、什么变了

**成立（现在是在两个配方下）：**
- 墙随类数陡峭增长然后**饱和** —— 形状是协议族的性质，不是调度的性质；
- **松紧在 C 上非单调**，在中段达到峰值 —— 两个配方下序列相同；
- **每个 C 都是零假排除**（S3），即：可证侧不受任何学生侧选择的影响；
- cp3 的墙 96，现在被独立复现。

**变了：**
- `alpha` 依赖调度（固定学习率 1.284 vs 余弦 0.890，形状相同）—— 所以引用拟合指数时应当带上它的配方，
  尽管定性形状是稳定的；
- "固定学习率抬高已定位的墙"这一主张作为一般化被撤回，替换为上面的相互作用表述；
- 实践规则变成：**把调度与预算一起选**（只在运行长到足以收敛时才退火），而不是"避免固定学习率"。

## 4. 诚实的边界

- 模式 A 有四个类数，在 sigma = 1.0 上各一个种子；模式 B 一个协议。饱和主张依赖顶部的两个相等值
  （C = 64 与 C = 216），与第 3 轮一样。
- C = 8 的"欠训练"解释是从赤字模式（K = 8：0.08 -> 0.24）和调度已知的行为推断的，不是直接测得的 ——
  直接检验会是在 C = 8 上用余弦加更长预算（例如 180 epoch），但没有跑。
- **CP-H（CIFAR-10 锚点，记录的墙 128-192）**：本笔记的第一稿说它记录的指纹*没有*使用 `--cosine` 标志。
  **那是错的，而这个错误值得记录**：在若干合理配置上重算
  `cph_demo.run_signature`，只在 **cosine=True（workers=4、lr=1e-3、120 epoch、宽度 96、全量数据）** 下复现出
  `0d8045d2`，其它配置都复现不出。因此 CP-H 记录的墙**本身就是用余弦退火测的**，而且是长预算（120 epoch）——
  这与上面的一切都一致：衰减调度配上长到足以收敛的预算就是好情况，而真实数据锚点一直就在这个情况里。
  CP-H **没有**的是它自己档位上的*固定学习率对照*，所以改为跑了一个配对的真实数据探针：同一个记录的教师、
  同一份数据、同一个初始化种子（22000+100s+K）和共享预算，只切换调度，另外把记录的 120 epoch 学生作为
  零训练锚点评估。它的结果报告在第 5 节。
- 台账：`ledger.md` E-026。产物：`experiments/data/wall_remeasure.jsonl`、
  `wall_remeasure_report.txt`、`wall_remeasure/`。

## 5. 真实数据：配对的 CP-H 探针（CIFAR-10）

既然记录的 CP-H 墙原来是**余弦**的结果（第 4 节的更正），那么有用的真实数据问题就是那个配对问题：
在**共享**预算下，调度会不会在 CIFAR-10 上移动保留率？
这个探针把记录的教师（acc 0.799）、全量 CIFAR-10 训练集、记录的初始化种子
（22000 + 100s + K）和一个 20 epoch 预算固定住，只切换调度；记录的 120 epoch 学生作为零训练锚点评估。

| K | 固定学习率（20 ep） | 余弦（20 ep） | delta | 记录（120 ep，余弦） |
| --- | --- | --- | --- | --- |
| 64 | +0.324 | +0.207 | **-0.118** | +0.169 |
| 128 | +0.275 | +0.189 | **-0.086** | +0.117 |
| 192 | +0.171 | +0.140 | **-0.031** | **+0.090** |

- **这个配方在真实数据上同样重要**（P1：最大 |delta| = 0.118，对照 0.03 的阈值），而且在这里方向
  **在每一档都是有利的**：在同样的预算下，余弦退火比固定学习率多保留参照模型的 3-12 个百分点。
  所以合成任务上的相互作用发现确实延伸到了本项目唯一的真实数据任务 —— 符号取决于任务与预算，
  与相互作用那个说法预测的完全一致（在 CIFAR-10 的 20 epoch 上有利；在 sigma = 1.0 的格点上短预算时有害）。
- **记录的墙被内部复现了**：记录的 120 epoch 赤字是 0.169 / 0.117 / **0.090**，
  它们在第 K = 128 与 K = 192 之间穿过 0.10 的保留率门槛 —— 记录的墙是 128-192。这个探针不只是没有与记录矛盾，
  它从同一批检查点重新推出了记录。
- **预算并不简单地就是好事**，又一次：在 K = 64，120 epoch 的学生（0.169）比
  20 epoch 的余弦学生（0.207）*更差*，而在 K = 128 与 192 上它更好。这就是 BUDGET-DOSE 在合成族上发现的那种内部最优
  行为，现在在真实数据上也看得见。

**判定：MIXED —— 配方效应延伸到了真实数据，附带的告诫是这是一个降档的档位**（20
epoch、一个种子、三个档）而不是 CP-H 记录的 120 epoch 档。它的价值在于*配对*：同一个
参照模型、同一份数据、同一个种子、同一个预算，只切换一个因子。

### 5b. 同一个问题在 CP-H 自己记录的档位上（2026-10-05 补）

上面的探针是一个降档的档位。记录自己的档位是全量 CIFAR-10 上的 120 epoch —— 而记录在那里没有
固定学习率的对照，所以跑了这一臂：同一个记录的教师、数据和初始化种子，120 epoch，只把
学习率固定为 1e-3。

| K | 固定学习率（120 ep） | 记录（余弦，120 ep） | delta |
| --- | --- | --- | --- |
| 128 | **+0.612** | +0.117 | **-0.495** |
| 192 | **+0.249** | +0.090 | **-0.159** |

**B1 PASS，而且效应很大**：在 CP-H 自己的档位上，固定学习率的学生几乎留不住参照模型
（K = 128 时为 +0.612），而记录的余弦学生保留了其中大部分（+0.117）。所以**记录的
128-192 这些墙之所以可能，是那个调度给的**：假如 CP-H 是用固定学习率跑的，它的学生在这些档上就不会
接近那道门槛，而墙会被报告得高得多 —— 或者根本定位不出来。这是本项目测到的配方效应
最强的真实数据实例（保留率上 0.495，对照降档探针里的 0.086-0.118），而且它处在相互作用中与
SCALE-C 各实例*相反*的那一端：在那里，更难的任务上短预算，退火欠训练；在这里，长预算
配上模型拟合得动的任务，固定学习率干脆训不动学生。

## 6. 墙为什么还是"饱和"在 512：一个细阶梯检验（2026-10-05 补）

重测留下了一个问题：在余弦下 C = 27 / 64 / 216 的墙是 128 / 512 / 512，
所以当类数变成三倍时*值*看起来停止了增长。有两个解释都吻合：(i) C = 64 与 C = 216 共享一条真实的保留
边界，或 (ii) 10% 的门槛是在一个平坦区域内部被穿过的，使得已定位的值变成判据本身的阈值产物。
一个**更细的阶梯**能把两者分开 —— 而答案与上面这两个说法都不相符。

| C | 更细阶梯上的赤字 | 墙（更细） | 墙（粗阶梯） | 穿越处的落差 |
| --- | --- | --- | --- | --- |
| 27 | +0.395 / +0.240 / +0.235 / +0.175 / +0.153 / +0.111 / **+0.089** / +0.060（K = 16…192） | **128** | 128 | 0.021 —— **软** |
| 64 | +0.285 / +0.179 / **+0.089** / +0.073 / +0.052 / +0.028 / +0.030（K = 128…1024） | **256** | 512 | 0.090 —— 锐 |
| 216 | +0.379 / +0.264 / +0.190 / +0.150 / **+0.015** / -0.013 / -0.053（K = 128…1024） | **512** | 512 | 0.135 —— 锐 |
| 512 | +0.395 / +0.234 / +0.123 / **+0.042** / +0.003 / -0.059 / -0.113（K = 256…2048） | **768** | 未测 | 0.082 —— 锐 |

- **墙一直在增长**：在 **18.96×** 的类数范围上为 128 / 256 / 512 / 768（墙的比值为
  **6.0**）。拟合已定位的墙得到

  > `ln K_wall = 0.603 · ln C + 2.944`，**R² = 0.988**，n = 4

  对照 SCALE-C 第 1 轮测到的**可证需求的** `K_min ∝ C^0.58`。两个斜率相差
  0.023，所以**墙与需求以基本相同的速率增长** —— 驱动这整条工作线的那个张力（"实测墙饱和而
  信息论需求持续增长"）是**粗阶梯的产物**，那个阶梯的顶部台阶之间相隔四倍。
- **锐利度是实例的性质，不是方法的通过/不通过。** 穿越那一档处的落差
  在 C = 27 是 0.021（那里差距曲线逐渐逼近门槛，所以已定位的值带有额外的
  阶梯不确定性），在 C = 64 是 0.090，在 C = 216 是 0.135，在 C = 512 是 0.082。这个
  判据的第一个版本要求*每一次*穿越都是锐的，这就把"这条边界是真的吗？"与"这条
  特定的差距曲线陡吗？"混为一谈；判据现在拟合增长率并逐实例报告锐利度。
  预注册的位置检验 A1 保留在代码的 docstring 里备查。
- **判定：对饱和主张是 REFUTED**（墙按 `C^0.60` 增长，R² = 0.988），附带诚实的告诫：
  四个点中有一个（C = 27）坐落在一次软穿越上，而且这些是单种子的学生阶梯
  （种子扫描报告在 §7）。

## 7. 种子扫描：两个头号结果都是种子稳健的（2026-10-05 补）

上面的一切都是单种子测量，这是本项目惯常的诚实告诫。因此对那两个分量最重的
结果做了种子扫描。

**（a）真实数据的配方效应，在 CP-H 记录的档位上**（K = 128，120 epoch，全量 CIFAR-10，宽度 96；
复用记录的教师、数据和按种子区分的初始化，只切换调度）：

| 记录的 CP-H 种子 | 参照 acc | 固定学习率（120 ep） | 记录（余弦，120 ep） | delta |
| --- | --- | --- | --- | --- |
| 0 | 0.799 | +0.612 | +0.117 | **-0.495** |
| 1 | 0.768 | +0.597 | +0.054 | **-0.543** |
| 2 | 0.803 | +0.614 | +0.093 | **-0.521** |

**3/3 个种子**，而效应的幅度只变化了 0.048。所以 §5b 的结论不是
种子意外：在它自己记录的档位上，CP-H 的墙之所以可能，是那个调度给的，而固定学习率
让学生在相对尺度上比参照模型低约 0.52。

**（b）增长指数**（C=216 的细阶梯用不同的学生初始化重跑）：

| 量 | 值 |
| --- | --- |
| C = 216 的墙，学生种子 0 / 1 / 2 | 512 / 512 / **384** |
| 该 C 上的种子散布 | 一个 **1.33** 的因子，即在一步阶梯之内 |
| 只用种子 0 的指数 | **0.603**（R² = 0.988，n = 4） |
| 把每个种子的点都折进来的指数 | **0.582**（R² = 0.966，n = 5） |
| 可证需求的斜率 | 0.58 |

拟合斜率在这两个拟合之间移动了 **0.021**，而且两者都与可证需求一致，所以
§6 的结论 —— 墙以基本等于需求的速率增长 —— 在换种子后依然成立。墙的
*位置*才是会移动的那部分（C = 216 上 384 vs 512），这正是锐利度与
容差带那套讨论所预测的：一道墙是一次阈值穿越，其已定位的值带有大约一步的、依赖阶梯与
种子的不确定性。

**保留的告诫**：按种子区分的指数需要*每个种子*三个类数；只有 C = 216 做了扫描，所以
关于种子的陈述覆盖的是：一个类数上墙的*位置*，加上再折进一个种子时指数的稳定性 ——
不是四个独立的拟合。

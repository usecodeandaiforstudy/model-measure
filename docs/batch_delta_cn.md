# 逐批 Delta：分布、分层选择与在线训练仪表

`capacity_lens.batch_delta`

纯函数：调用方提供实测损失与梯度，本模块不训练、不读文件。

## API

| 函数 | 含义 |
| --- | --- |
| `per_batch_delta` | 每批 `Delta(b) = L_probe(theta_b) - L_probe(theta_full)` |
| `delta_summary` | 均值、标准差、变异系数、极值批次 |
| `rank_batches` / `select_batches` | 排序与 high/low/middle/random 分层（确定性） |
| `online_step_delta` | 在线逐批 Delta：`-lr * <g_probe, g_b>`，每步只多一次反传 |
| `track_probe` | 跨批变异，以及逐轮均值跟随探针损失的程度 |

## 实测

| 量 | 值 |
| --- | --- |
| 每批 Delta 分布（40 批 × 100 张） | 均值 **+0.4255**，标准差 0.0905，**变异系数 0.213**，复跑一致 |
| 与类别熵的相关 | **-0.523**（越均衡代价越小） |
| 与批次自身拟合损失的相关 | -0.061（拟合得好并不说明 Delta 小） |
| 分层选择（等大小、等熵） | 高 **0.8803** vs 低 0.8697（**+0.0107**） |
| 类内（每类固定 200 张） | 难 **0.8952** vs 易 0.8400（**+0.0552**） |
| 按 Delta 加权抽样 | **0.8712**，比随机 0.8752 更差 |
| 在线一阶值 vs 精确一步 | 相关 **+1.000** |
| 在线逐轮均值 vs 真实探针损失 | Spearman **-0.969** |
| 在线跨批变异 | sd/|mean| **0.10** |
| 在线做坏批次检测（损失已匹配） | AUC **0.641 → 0.491**，而批次损失 0.611 → **0.847** |

## 能声明 / 不能声明

| 可以声明 | 不能声明 |
| --- | --- |
| 每批 Delta 有变异且可复现 | Delta 大就一定泛化更好 |
| 按 Delta 排序/分层能拿到点数 | 把 Delta 当采样权重（输给随机） |
| 在线值忠实反映一批对探针集的影响 | 在线值比批次损失更能发现坏数据 |
| 跨批变异可测（10%） | 该信号训练后期仍有效（ep20 后失效） |
| 探针测得的 Delta 不能读作测试集上的预期改善（高估 4–5 倍） |

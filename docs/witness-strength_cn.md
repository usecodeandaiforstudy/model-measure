# 见证者笔记（witness-strength）

> 记录日期：2026-09-30  实验：`experiments/witness_demo.py`（预注册判据在该脚本的 docstring 里）
> 问题的来源：需求读数 `R_IB` 是**见证者相对**的（由参照模型达到的误差经 Fano 反解而来）。当时有两个问题悬而未决：
> （1）见证者可以便宜到什么程度而仍然可用？（2）见证者能否被一种"直接从标签读出"的读数（`H(Y)=ln C`）取代？

---

## I. 设计与预注册

| 条目 | 内容 |
| --- | --- |
| 任务 A | 干净 grid64（一个 64 类的确定性任务；编码常数逐字抄自 `cifar_demo.make_grid64_images`） |
| 任务 B | 合并类 grid64：8 个模板 × 每模板 8 个**不可学**的重复标签 → `H(Y)=ln64=4.159` 而 `H(Y\|X)=ln8=2.079`，贝叶斯天花板 ≈ **0.125** |
| 见证者阶梯 | W1 = 1-NN（原始像素，**零训练**）/ W2 = 线性探针（秒级）/ W3 = 同架构 CNN **4ep** / W4 = 同架构 CNN **40ep**（校准参照，同时也是 KD 教师） |
| 仅标签对照 W0 | 需求 := `ln C`（无模型） |
| 实测真值 | 由 W4 蒸馏出的学生网格（K 变化、其余固定）；`rel(K) = gap/acc_W4`，成功为 `rel≤0.10`，失败为 `rel≥0.50`（相对阈值；修订记录在脚本 docstring (3) 中） |
| 判据 | T1 `R_IB` 沿阶梯非递减；T2 **可靠性**：任何见证者都不得排除一个可测地匹配参照模型的学生；T3 覆盖廓线；U1 仅标签的假排除计数 |

## II. 结果（3 种子 / 2 种子）

**任务 A（干净 grid64）**

| 见证者 | acc | R_IB | K_min | 覆盖 | 假排除 |
| --- | --- | --- | --- | --- | --- |
| W1 1-NN（0 ep） | **1.000** | 4.16 | 64 | **1.00** | 0 |
| W2 线性探针 | 0.832–0.839 | 3.01–3.05 | 21–22 | 0.70–0.78 | 0 |
| W3 CNN 4ep | 0.796–0.836 | 2.81–3.04 | 17–21 | 0.70–0.78 | 0 |
| W4 CNN 40ep | 0.999–1.000 | 4.15–4.16 | 64 | 1.00 | 0 |
| W0 仅标签 | — | 4.16 | 64 | — | 0 |

**任务 B（合并类 grid64，贝叶斯天花板 0.125）**

| 见证者 | acc | R_IB | K_min | 覆盖 | 假排除 |
| --- | --- | --- | --- | --- | --- |
| W1 / W2 / W3 | 0.117–0.124 | 0.14–0.15 | 2 | 0.00 | 0 |
| W4 CNN 40ep | 0.122–0.134 | 0.15–0.18 | 2 | 0.00 | 0 |
| **W0 仅标签** | — | **4.16** | **64** | — | **2** |

W0 的两例假排除：`K=32`（种子 0）与 `K=16`（种子 1）——**可测地匹配参照模型**，却被 "`K < C` ⇒ 装不下" 判死。

### 扩展运行（`--extend-top`，2026-09-30，复用已缓存的基础档位做追加测量）

基础网格的顶端止于 K=64（恰好落在墙上），且没有"孪生学生"档位，因此任务 A 的"实测成功集"注定为空（那条很长的 KD 尾部衰减）。在追加 A:`+[128,192,256]` 与 B:`+[128,256]` 之后，测量结果为：

| | 实测成功集 S | 实测失败集 F |
| --- | --- | --- |
| 任务 A 种子 0/1/2 | `[128,192,256]` / `[192,256]` / `[128,256]` | `[2..48]`（K=64 落在灰区：保留率 50–90%） |
| 任务 B 种子 0/1 | `[32,64,128,256]` / `[16,256]` | `[2,3,4]` / `[2,3,4,6]` |

**T2 由此成为一次真正的检验**：各见证者的被排除集（W1/W4 到 48，W2/W3 到 16）与成功集（≥128）**两侧都非空且互不相交** → 无假排除，**但安全余量很大**（被排除集上界 48 对成功集下界 128，中间的档位 64 落在灰区）。判据与其余结论不变（MIXED；U1 依然是 2 例假排除）。

### 任务 C（真实 CIFAR-10 任务，复用 CP-H 缓存；`--task C`）

**设计**：参照 W4 = CP-H 校准教师（SmallCNN width96 / K=256 / 120ep cosine，acc 0.799 / 0.768 / 0.803，**零训练**）；实测真值 = CP-H 学生网格（13 档 × 3 种子，**从缓存读出**）；三个新的廉价见证者：W1 原始像素上的 1-NN（memory 2000 / query 1000，零训练），W2 岭回归线性探针（原始像素，10000 样本训练子集），W3 = 同架构 CNN **8 epoch**（比 CP-H 预算便宜 15×）。

| 见证者 | acc | R_IB | K_min | 被排除集 | 覆盖 | 假排除 |
| --- | --- | --- | --- | --- | --- | --- |
| W1 1-NN 原始像素 | 0.243 | **0.08** | 2 | ∅ | 0.00 | 0 |
| W2 线性探针 | 0.303 | 0.16 | 2 | ∅ | 0.00 | 0 |
| W3 CNN 8ep | 0.517–0.571 | 0.55–0.68 | 2 | ∅ | 0.00 | 0 |
| **W4 CP-H 教师** | 0.768–0.803 | **1.25–1.37** | 4 | `[2, 3]` | **0.33–0.40** | 0 |
| W0 仅标签 | — | 2.30 | 10 | `[2,3,4,6,8]` | — | **0** |

实测：成功集 `{192,256}` / `{128,192,256}` / `{128,192,256}`；失败集 `{2,3,4,6,8}`（种子 1 还包含 12）。

**判定（仅任务 C 的预注册聚合）= SUPPORT**：T1 PASS（R_IB 单调 `0.08 → 0.16 → 0.65 → 1.36`，跨度 **17×**），T2 PASS（零假排除），T3 **STEEP**（覆盖 `0 → 0.40`）。**三个任务合并的总判定 = MIXED**（聚合规则是"全部任务"，而 A/B 未通过 T1）。

**这就是在一个真实任务上对"见证者强度值多少"的回答**：

- **在这个任务上，廉价见证者给出的界是零** —— 原始像素 1-NN、线性探针，乃至 8 epoch 的 CNN，覆盖全都是 **0**；
- 只有校准过的教师排除了 2 个档位（覆盖 40%），**但即便如此它也远未触及成功边界**（排除 `{2,3}` 对成功 `≥128`）—— Fano 界与实测墙之间的"32× 余量"（由 CP-H 记录）在这里再次出现；
- **与任务 B 的对比**：在任务 C 上，仅标签读数（`K<10`）**没有**产生假排除 —— 因为 CIFAR-10 的细粒度区分是可学的。这确认了"仅标签"的失效条件是**任务含有不可学的细粒度结构**，而不是"任务很难"。

## III. 判定（按预注册，原样保留）

**判定随"聚合范围"而不同；两种读法都已记录**：

- **三个任务合并（`--task all` 的聚合，即脚本的默认约定）= MIXED**：因为该聚合要求**全部任务**通过 T1，而任务 A/B 没有（成本阶梯非单调）；T3 在 A/B 上是 SHALLOW。
- **仅任务 C（`--task C` 的聚合）= SUPPORT**：T1 PASS，T2 PASS，T3 **STEEP**（覆盖 0 → 0.40）。

逐任务细节：

| 任务 | T1 单调性 | T2 可靠性 | T3 覆盖 | U1 仅标签假排除 |
| --- | --- | --- | --- | --- |
| A（干净 grid64） | **FAIL**（免费的 1-NN 最强，4.16 > 3.04 > 2.89） | PASS（扩展后非空且成立） | SHALLOW（W1/W4 都是 1.00） | 0 |
| B（合并类 grid64） | **FAIL**（非单调） | PASS（被排除集为空 → 一次弱检验） | SHALLOW（全为 0.00） | **2（命中预测）** |
| C（CIFAR-10） | **PASS**（0.08→0.16→0.65→1.36） | PASS（零假排除） | **STEEP**（0 → 0.40） | 0 |

## IV. 结论

1. **"仅标签"是被测量否证的，而不只是被论证否证的**：在一个细粒度区分不可学的任务（B）上，它把**可测地匹配参照模型**的学生判死（2/2 种子）；而在细粒度区分可学的任务（A/C）上，它不产生假排除。⇒ 失效条件是**任务含有不可学的细粒度结构**（`H(Y|X) > 0`），而不是"任务很难"。
2. **见证者强度与训练成本无关**（这就是 T1 在 A 上被否证的真正含义）：**零训练的 1-NN 在干净任务上和 120/40 epoch 的教师一样强**（acc 1.000），而线性探针与 4ep CNN 反而很弱（0.83）。挑选见证者的标准是**达到的精度**，不是预算。
3. **在真实任务上见证者强度确实决定判据的可用性**（C 的 T1/T3）：R_IB 跨度 **17×**（0.08 → 1.36 nats），覆盖 **0 → 0.40**；原始像素见证者（1-NN、线性探针）乃至 8ep CNN **完全不给出排除**。
4. **但即便在真实任务上，这个界也远未触及成功边界**：最强的见证者只排除 `{2,3}`，而实测成功从 `K=128` 开始 —— Fano 界与实测墙之间的"32× 余量"（CP-H）在这里第二次出现。⇒ **限制判据可用性的主要因素不是见证者强度，而是 Fano 界自身的松紧**；这与 MOE 实验的结论指向同一方向（流量层的锚点必须是**实测墙**，而不是 Fano 下界）。
5. **可靠性（T2）全程零假排除**：在 A 上网格扩展之后它是一次真检验，在 C 上被排除集与成功集两侧非空且互不相交。不足之处在于**始终没有一次"贴着边界"的检验**（A 的 K=64 与 C 的 12–64 都落在灰区，没有任何见证者排除它们）。

## V. 边界

- 三个任务：**A** 干净 grid64（3 种子，基础网格 11 档 + 顶端扩展 3 档），**B** 合并类 grid64（2 种子，8 + 2 档），**C** 真实 CIFAR-10（3 种子，13 档；参照与学生网格都从 CP-H 缓存读出，只新增一个 8ep 廉价 CNN 见证者）；
- 网格指纹只覆盖**基础网格**（项目约定，research-summary §10.4）：顶端扩展复用了每一个缓存的基础单元，只新训了 13 个单元；任务 C 复用了 CP-H 的 42 个缓存单元；
- 任务 B 的参照模型必然 FAIL 校准过的 G0 acc 门（任务自身的天花板是 0.125）；脚本已声明该门在此不适用（Fano 只需要一个"达到的误差"）；任务 C 的参照模型（0.768–0.803）同样低于默认的 0.95 门 —— CIFAR-10 的校准门是 CP-H 记录的 **0.78**，脚本按"只报告、不过滤"处理；
- 任务 C 的 W3 见证者使用**廉价协议**（8ep，无 cosine），不同于 CP-H 的 120ep cosine 预算；这是构造上的差异（已记录）。

## VI. 更正与追加记账（同日）

1. **判定聚合崩溃**：`is_monotone` 被传入了一个 dict → `vals[1:]` 抛 KeyError；改为按阶梯顺序取值，自测夹具也相应改为 dict。
2. **命中的缓存教师没有放进 `eval()`**：BatchNorm 使用了批统计量 → KD 软标签与首次运行不同，因此在缓存混用的情况下学生结果不可复现；已在 `rebuild()` 中加入 `m.eval()`。
3. **指纹违反项目约定**：最初整个学生网格都进了指纹，于是新增一个档位就让一切失效；改为只有基础网格进指纹（约定见 research-summary §10.4），并为顶端扩展新增 `--extend-top`。
4. **新增任务 C（CIFAR-10）**：`--task C` / `--task all`；参照与实测真值复用 CP-H 缓存，判据集合不变（记录在脚本 docstring (10)）。

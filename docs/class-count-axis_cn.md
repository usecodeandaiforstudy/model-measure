# 尺度（类数轴）笔记（class-count-axis）

> 记录日期：2026-09-30 · 实验：`experiments/scale_c_demo.py`（判据预注册在脚本 docstring 里）
> 问题：当**类数 C 放大 125×**（C = 8 → 1000）后，工具的两侧 —— 可证的**需求/排除**与实测的**墙/松紧** —— 是否依然成立？
> 为什么只做 C 轴：见"不下数据能不能做尺度实验"的分析 —— C 是唯一几乎不花算力（只改分类头）且能离线跨越 100× 的轴；
> 本机只有 CIFAR-10/MNIST 和 8 GB 显存，所以"自然多样性 / 大规模预训练 / 224×224"这三条轴无法离线完成。

---

## 1. 设计与两处设计更正（都有记录）

- **任务**：本项目自己的 3 维格点族（`mnist_demo.make_grid64` 的 m=4 特例推广到 m³）：C = m³，
  m ∈ {2,3,4,6,10} → C ∈ {8, 27, 64, 216, 1000}；**格胞几何完全不变**（间距 3.0、噪声 σ），
  每类 150 个样本，80/20 划分，2 个种子。
- **模型**：`Linear(3→64) → ReLU → bottleneck(64) → Linear(64→C)`；**参照模型不带瓶颈**，学生 VQ(K)、KD、60 epoch、Adam 1e-2。
- **σ 标定（选择过程有记录）**：先在 σ ∈ {0.5, 1.0, 1.5, 2.5} × 5 个 C 值上扫了一轮（20 epoch）：**σ=1.0 是唯一让五个类数都落在信息带 0.02–0.60 内的设定**（ε = 0.158/0.275/0.318/0.365/0.451），故采用 σ=1.0。
  **锚点校验**：在 σ=0.5 时 m=4（C=64）给出 ε=0.035，与 cp3 的 MLP 已测到的 0.014–0.039 吻合 ✓
- **设计更正 1（参照模型必须有容量）**：如果参照模型保留 256 码字的瓶颈，那么在 C ≥ 256 时**参照模型自己就被堵住了**（它需要 `ln C ≥ 5.5` nats 而 `log 256 = 5.55`）—— 测到的是参照模型的瓶颈，不是任务。所以参照模型改为**不带瓶颈**。
- **设计更正 2（被放弃的合成族）**：先试了三个合成族 —— "白噪声投影 / 固定平滑基 / 自相似基" —— 三个都在测量中失败（C≥256 永久停在随机水平；有一个版本在 C=10 时甚至训不动，因为基向量是单位*范数*而不是单位*逐像素 RMS*，使信号弱了 55×）。**换成项目自己的格点族第一次就通过了**，而且能对着 cp3 做锚定。

## 3. 四条结论

1. **需求侧在 1000 类上完全跟着公式走**：`R_IB` 从 **1.18 → 3.32 nats**（C 8→1000），`K_min` 从 4 → 28（次线性，ε≈0.42 时 `K_min ∝ C^0.58`）。公式本身还是同一个函数，但**它的输入是在 1000 类模型上实测的 ε** —— 这一侧在尺度上没有出问题。
2. **健全性跨越 125× 依然存活**：**十个实例零假排除**（含 C=1000）⇒ 头号规则 `log K < R_IB ⇒ cannot fit` 在尺度上仍然安全。
3. **`ln C` 天花板被"相对地"抬高了，但绝对触达范围仍由错误率支配**：`K_min/C` 从 **0.50（C=8）降到 0.028（C=1000）**，即天花板约束**松了 18×** ⇒ 尺度越大，工具的排除越有余地（预注册的 P1 部分确认）；但绝对地看被排除集合只从 1 档长到 2 档，因为 ε=0.42 把 `R_IB` 钉在 3.32，远低于 `ln 1000 = 6.9`。**⇒ 在尺度上真正起约束作用的已经变成"可达错误率"，而不是"类数天花板"。**
4. **墙在尺度上定位不出来 —— 而它失败的方式本身就是一条结论**：在 C ≥ 27 时，学生在 K 网格内任何位置都追不上参照模型（**C=1000 时，K=512（`log K = 6.2` nats，已是需求的 1.9×）仍有 66% 的相对差距**）。相比之下 cp3（C=64，其教师本身就带 256 码字 VQ）的墙在 K=96 ≈ 需求的 **1.2×** ⇒ **实测墙是"参照–学生配对"的性质，不是任务的性质**。这是 LOOSENESS 那句"`K_wall` 依赖协议"的加强版（效应量大得多）。

## 4. 这轮暴露出的两个可修缺陷（供重跑）

1. **网格上限规则砍掉了自己的证据**：脚本里的 `if K > 2C: continue` 把大 K 点去掉了 —— C=216 时跳过 K=512，C=1000 时跳过 K=2048，**而墙恰好就坐在这些位置上**。重跑应改成 `K ≤ 8C` 或不设上限（把 K 网格给到 8192）。
2. **参照模型应当是"与学生同族"的架构**：这轮的参照模型不带瓶颈（为了满足"大 C 下参照模型自己必须有容量"），代价是**VQ 学生要去追一个连续表征的教师**，差距巨大。更好的做法：给参照模型一个**大而有限的 VQ**（例如 K_t = 8C），这样它既不被自己的瓶颈堵住，也不与学生的量化族不同族（CP-H/cp3 就是这么做的，这也是它们的墙落在需求 1.2× 处的原因）。

## 5. 关于"尺度边界"问题的净结论

- **可证侧（需求 + 排除）在 125× 类数上稳健**：精确缩放、零假排除，且天花板约束相对更松；
- **实测侧（实测墙 + 松紧）在尺度上仍未测出**：这轮的失败是可诊断的（上面两个缺陷），并不能作为"墙不存在"的证据；
- **顺带确认的一条方法论教训**：在尺度上，"参照模型自己必须有足够容量"（否则你测到的是参照模型的瓶颈）与"参照–学生必须同族"（否则你测到的是蒸馏难度）**同时成立** —— 两者在小 C（CIFAR-10/MNIST）上都不会暴露，所以它们是**尺度特有的方法论要求**。

## 6. 第 2 轮（更正协议）：墙定位出来了，却暴露出一个"需求–参照"三明治

**判定 = PARTIAL**：S4（每一档零假排除）**PASS**，S5（触达范围增长：[2] → [2,8]）**PASS**，**S3（松紧非递增）FAIL** —— 实测松紧**升了 2.09 → 3.20 → 3.44**，与第 1 轮预注册的方向预测相反。

### 6.1 主要发现：实测墙被"需求"与"参照容量"夹在中间

三个已定位的剂量都满足 **`K_min ≤ K_wall ≤ K_t`**：C=8 时 `3 ≤ 8 ≤ 64`，C=27 时 `5 ≤ 128 ≤ 216`，C=64 时 `7 ≤ 512 = K_t`（**贴着参照模型的瓶颈饱和**）。
再加上第 1 轮的结果（参照模型**不带瓶颈**）—— 同一个任务的**墙定位不出来（>2048）** —— 就得到一个**受控对照**：

> **同一个 C=64 任务、同一个 σ、同一个预算、同一个架构、同一个网格**，只改参照模型：
> 参照模型不带瓶颈 ⇒ 墙 **>2048**；参照模型 `K_t=512` ⇒ 墙 **=512**。**只换参照模型，墙就移动了 ≥4×** ⇒ 实测墙是"任务–参照"配对的性质。

> **这件事现在的定位（2026-10-05 补，`wall-saturation.md`）。** "任务–参照配对"这个读法
> 太窄了：后来证明墙并不响应任务的真实信息（一个 10× 更好的见证者把它留在
> 512），却强烈响应*学生的训练预算*（3× 的 epoch 把保留赤字减半）。正确的
> 说法是墙是**协议相对**的 —— 它由学生在蒸馏目标下收敛到什么程度决定，
> 而不是由任务的需求决定。本节作为那一轮测到了什么的记录仍然成立。

这也解释了本项目此前所有的墙读数：cp3（C=64，`K_t=256`，墙 96）与 CP-H（CIFAR-10，`K_t=256`，墙 128–192）**都落在它们各自的 `[K_min, K_t]` 区间内**，而且都没有贴着 `K_t` 饱和。

> **更正（由 §7 的固定天花板运行给出）**：本节原来写的"C=64 贴着 `K_t=512` 饱和"是**错的**。把天花板抬到 `K_t=2048` 后，C=64 的墙**仍然是 512** ⇒ 那个剂量并不是被天花板限制的（`8C=512` 与真实墙 512 只是数值上恰好重合）。所以"墙的上界 = 参照模型的容量"只有在**参照模型是连续的（未量化）**时才表现为"墙被推出网格之外"；参照模型量化时，墙的上界显然 ≥ 实测墙，而真实墙由**任务 + 蒸馏协议**决定。

### 6.2 α 是怎么测的，以及它的局限

三个已定位的墙给出 `ln K_wall = 2.018·ln C − 2.023`（**R² = 0.991**，n=3）⇒ 墙 ∝ C²。第 1 轮担心这个 α 被 `K_t = 8C` 污染；**§7 的固定天花板运行（`K_t=2048` 在各 C 上不变）给出同样三个墙 8/128/512**，说明在 C ≤ 64 范围内这个 α **不是天花板造成的**（细节见 7.1）。
再补一句：给定 α 拟合，S3 的"渐近值"条款（松紧 → `α/(1−ε)`）**近乎同义反复**（`looseness = ln K_wall/R_IB` 而 `R_IB ≈ (1−ε)ln C`）；实测的 `2.018/0.596 = 3.38` 与松紧 `3.44`（差 0.06）确实吻合，但它**不是独立证据** —— 真正有实质内容的方向性条款被否证了（官方判定：Spearman = **+1.000**，n=3）。

### 6.3 更正后的结论与下一步

- **需求侧再次稳健**：`R_IB` 0.99 → 2.34 nats（C 8→216），`K_min` 3 → 11，**零假排除**，触达范围在增长 ✓；
- **墙的可测性取决于参照模型的量级**：`K_wall ∈ [K_min, K_t]` 是这一轮给出的结构性三明治；
- **下一轮（干净设计，预算约 2–3 小时）**：`K_t` **固定为 8192**（上界不随 C 移动）+ 网格顶部细化到比值 2（`…,512,1024,2048,4096,8192`，避开本轮 C=216/1000 撞上的网格空隙）⇒ 只有到那时才能给出**任务自己的** α 与 `looseness(C)`；
- **性能备注**：当 KD 的教师带 8000 个码字时，每一步都要算 `cdist(128×8000)`，单元耗时从 5.5 分钟涨到 **18 分钟**；固定 `K_t=8192` 要付同样的代价，所以预算必须相应估算。

## 7. 第 3 轮（干净设计：天花板固定）：α 去污染，墙是"先陡后饱和"

**设计**（运行前记录）：`K_t = 2048` **在所有 C 上固定**（`log 2048 = 7.62 ≥ ln 1000 = 6.91`，所以在任何 C 上它都不是瓶颈）；学生网格加宽为 `[2,8,32,128,512,1024,2048]`，顶部比值 2；其余（任务、σ=1.0、150 样本/类、60 epoch、Adam 1e-2、种子 0）与第 2 轮相同。
**性能修复**：教师的 logits 按实例**缓存一次**（fp16），学生循环读缓存 —— 那个循环是包内 KD 目标的**逐行复刻**，在 `--selftest` 里做了数值校验（**损失逐位一致：2.6661 vs 2.6661**）。这把每实例开销从第 2 轮的 18 分钟/单元降到本轮的 0.1–13 分钟/单元（C=1000 时全部实例 67 分钟：参照 340 秒 + 缓存 2 秒 + 7 个学生 3656 秒）。

| C | ε | R_IB | K_min | 被排除集合 | **K_wall** | 松紧 |
| --- | --- | --- | --- | --- | --- | --- |
| 8 | 0.175 | 1.28 | 4 | `[2]` | **8** | 1.63 |
| 27 | 0.296 | 1.72 | 6 | `[2]` | **128** | 2.82 |
| 64 | 0.348 | 2.07 | 8 | `[2]` | **512** | 3.01 |
| 216 | 0.446 | 2.29 | 10 | `[2, 8]` | **512**（停止增长） | 2.72 |
| 1000 | 0.613 | 2.01 | 8 | `[2]` | 未定位（K=2048 时仍差 0.26） | — |

**判定 = MIXED/REFUTED**（S4 通过；S3 的方向 ✗，S5 ✗）：S2 `ln K_wall = 1.284·ln C + 0.066`（**R²=0.830**，n=4）；S3 的方向 Spearman **+0.400**（松紧**非单调**）；S5 的触达范围没有增长，因为最大的 C 落到了信息带之外（ε=0.613 > 0.60）。

### 7.1 三条有实质内容的结论

1. **预注册的预测命中**：第 2 轮担心"α 被 `K_t=8C` 污染"；本轮把 `K_t` 固定为 2048 后，**α 从 2.018 降到 1.284** ⇒ 第 2 轮的 α 确实偏高（因为天花板随 C 移动）；去污染后墙的缩放**显著低于 2**。
2. **墙不是单条幂律，而是"先陡后饱和"**：8 → 128 → 512 → **512**（C=216 与 C=64 共享 512）⇒ 在这个任务族里，墙在 C≈64（≈2.4×C）之后停止增长，所以对四个点拟合单条幂律得到的 α=1.284（R²=0.830）本身只是**两个区段的平均**。
3. **松紧在 C 上非单调**（1.63 → 2.82 → **3.01** → 2.72）：机制很清楚 —— `R_IB` 随 `ln C` 缓慢上升，而墙在低 C 段先陡升然后饱和 ⇒ **松紧在中段（C≈64）达到峰值然后回落**。这是对派生预测"松紧在 C 上非递增"的**第三次否证**；正确的表述是**"松紧没有单一方向 —— 它取决于墙处在增长段还是饱和段"**。

### 7.2 健全性与天花板

- **S4 第三次独立通过**：五个 C 值（含 1000 类）**零假排除** ⇒ 头号规则在 125× 的类数跨度上复现三次；
- **更正第 2 轮的"饱和"说法**：本轮 `K_t=2048` 下 C=64 的墙**仍是 512**，与第 2 轮 `K_t=512` 时相同 ⇒ 那个剂量不是被天花板限制的；第 2 轮的"贴着 `K_t` 饱和"是数值巧合（§6.1 已更正）；
- **C=1000 的参照模型偏弱**（ε=0.613，落到 S1 带外）：150 样本/类 × 60 epoch 在 1000 类上是欠训练的；这是 **S5 失败的机制**，是协议问题，不是尺度的性质；它的墙也没定位出来（最大 K=2048 时仍差 0.26）。

### 7.3 对"尺度边界"问题的最终回答（类数轴）

- **可证侧在 125× 类数上稳健**（三轮一致：需求精确缩放、零假排除）；
- **实测墙的缩放**：去污染后 α≈1.28，但真实形状是**先陡后饱和**；在这个任务族里墙封顶在 ~512；

> **更正（2026-10-05，`wall-remeasurement.md` §6）。** "饱和在 ~512"这个读法是**阶梯的
> 离散化产物**：粗网格在 128 与 512 之间没有档，所以 C=64 的真实穿越点（~256）无法
> 分辨，两个 C 值都报了 512。在细阶梯上 —— 现在已在四个类数上测过 —— 墙是
> **128（C=27）、256（C=64）、512（C=216）、768（C=512）**，类数比 **18.96** 对应墙比
> **6.0**，拟合为
> `ln K_wall = 0.603·ln C + 2.944`（**R² = 0.988，n = 4**），对照下面测到的第 1 轮
> 可证需求 `K_min ∝ C^0.58`。两个斜率相差 0.023：**一旦阶梯能分辨那个穿越点，墙与需求就以基本
> 相同的速率增长**，所以上面"先陡后饱和"那句话只作为关于粗阶梯的陈述成立。
> 一个逐实例报告的告诫：穿越在 C=27 是*软*的（赤字跨过它下降 0.021），在 C=64/216/512 是锐的（0.090/0.135/0.082）。
- **松紧在尺度上的行为**：**非单调**（在中段达到峰值）；它的形状由"墙处在增长段还是饱和段"决定，而不是单独由 C 或 ε 决定；
- **仍未覆盖**：分辨率、样本数、参数量与自然多样性这四条轴 —— 前三条此后已在 `scale-axes.md` 中测过，自然多样性离线仍然不可达 —— 外加 C=1000 上一个更称职的参照预算（见 §7.4，现已试过）。

### 7.4 后续：C=1000 用三倍学生预算（2026-10-05 补）

## 8. 边界（诚实的）

- 三轮合计：单一任务族（3 维格点）、单一架构（64 宽 MLP），而且**"尺度"只指类数**（分辨率/样本数/参数量/自然多样性这四条轴离线不可得）；第 1 轮是 10 实例 × 2 种子，第 2 轮 4 实例 × 1 种子，第 3 轮 5 实例 × 1 种子；
- C=1000 的算力事实：第 1 轮是每实例 25–33 分钟（参照模型不带瓶颈）；第 2 轮涨到 **18 分钟/单元**，因为参照模型带了 8000 个码字；第 3 轮用**目标缓存**把它降回 **67 分钟/实例**（含 7 个学生）；
- **松紧在尺度上的行为不再是空白**：答案是**非单调**（§7.1 第 3 条），其形状由墙处在增长段还是饱和段决定；但"墙为什么饱和在 ~512"背后的机制还没有找到（候选：KD 进入 VQ 学生的可模仿上限、任务族的 3 维格点结构、64 宽表征的容量）—— 那是下一个要问的问题；
- 要在 C=1000 定位墙，需要更强的参照模型（更大的预算）和更大的 K 网格（本轮在最大值 2048 处仍差 0.26）。

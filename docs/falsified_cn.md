## I. 预测路线的负结果（原 README"附录 1"，已穷尽判死）

这些实验试图用容量 / 区分度读数**预测** cliff 可定位性或网络性能。它们**不是**工具的组成部分，全部以负结果收场（提炼见 framework.md §4；三轴判定见 framework.md）。

| 线 | 模型 | 实验 | 验证了什么 |
| --- | --- | --- | --- |
| 合成 | MLP-d64 | CP1 | **cliff 可定位性预测判据**：表征簇结构指标（silhouette）在蒸馏前预测 cliff 可否定位，留出臂验证（**诚实负结果**：预测被证伪） |
| 合成 | MLP-d64 | CP2 | **码本余量剂量-反应**：干预 teacher 码本 K_t 扫余量轴 m=H(Z_t)-ln C，先预测后验证（**诚实负结果，fast/full 双跑一致**：K_t=96 误判；K_t=128 在 full 下 m 升入灰区自动判"不可判定"、fast 下误判；阳性对照 K_t=256 命中。有效剂量 9/9 全 locatable，K* 稳定于 96-128 ≈ 2×K_min。附带 L_info/Fisher-Rao 弧长首航：窄信道 teacher 弧长 5-8 倍于宽信道） |

| 合成 | MLP/CNN × euclid/cosine | CP3 补测② L_func | **预测翻转累积：唯一存活的 ρ 预测量**。L_func = Σ_epoch 固定探测集预测翻转率，在预测空间测量、等价解漂移不贡献。CNN 主对照可分（euclid 4.38 vs cosine 1.37，差 68.6% > 最大极差 2.35）；MLP 同向（3.95 vs 7.32）；全部 12 单元末轮 flip=0（预测冻结，翻转只发生在训练中段） |
| 合成 | CNN × euclid/cosine | L_func 稳健性三连 | **敏感性 → 8 种子 → 早窗全部通过**：① 4 探测集（内容/大小/泛化）同轨迹累积，结论 4/4 一致可分；② 8 种子逐种子零重叠（euclid 最小 3.18 > cosine 最大 1.51，16/16 阈值完美分类；漂移型种子 2/8 抬高全量极差，均值边际收窄至 1.03）；③ 早窗：前 2 轮即零重叠、前 5 轮余量 4×，K=10 边际 2.46× 反优于全量 1.03×（污染全量统计的漂移 ep10 后才积累，cosine 格 ep10 后预测冻结）。**早窗 reward 成本 = 完整训练的 1/8–1/20** |
| 合成 | CNN-euclid × K_t∈{128,256,512} | 多水平剂量（轴 A：teacher 码本） | **预注册 (4)-b 触发：L_func 追踪的不是 ρ**。K_t=512 全种子 G0 过、K\*=[192,192,192] 与 256 逐位相同（**K\* 上侧粘性跨架构成立**：H(Z_t) 5.2→5.8 而 ρ=3.00 不动），但 L_func@10 从 3.59±0.16 降至 1.19±0.12（差 2.40、零重叠，512 teacher ep10 起预测冻结）；K_t=128 acc 门全挂（40ep 0.73–0.83；80ep 重标定后仍 0.83–0.90 且增量收益递减 +0.05~+0.10=容量压力区而非预算不足，按修订条款**终局无效**——**该判定已被 PA1 翻案，见第 III 节**；早窗 L_func@10=6.22–6.41 与 40ep 运行逐位相同——早窗读数的预算不变性顺带实锤）。**结论：L_func = 结构-任务对的拟合代价（训练重组成本），沿度量轴与码本轴均单调响应且逐种子可分；ρ（盈余比）降级为诊断量，reward 重定位为 L_func + 成本/盈余约束（容量贪婪风险待优化器设计处理）** |
| 合成图像 | CNN（grid64 + shape64） | CP-D 区分度（检测理论口径） | **把"区分度"从聚类几何改定义为功能空间的判决裕度，并与训练难度对照**：`m(x)=logit(y_true)−max_{j≠y_true} logit(j)`（log-odds，不饱和）、`D=Q_5%(m)/MAD(m)`（尺度无关的 d'）、固定窗口 e0=10 关早停强制训满（e0=2 作早期参照）。**指标的两处修订均因阶段 0 实测退化**：概率差口径在 1/4 单元上 `MAD=0` → 指标无定义（56/108 单元中的 25 个），故换 log-odds；`min_c(class median)` 是 64 个类中位的极值、跨种子乱跳（同配置 −1.000/+0.985），故换 5% 分位。**J1 健全性 54/54 通过（两任务）；J0 训练复用自检 54/54 逐位一致**（重训与主运行同源）。**判定为诚实负结果**：J3 grid64 方向判据不过（rho −0.29/−0.00/−0.23）、shape64 方向过（−0.73/−0.68/−0.82, 3/3 ≤ −0.5）但**可分性两任务 0/3**；J4 两任务都未通过；J5 两任务符号相反（grid64 D 0.23 > L_func 0.16 > acc 0.06；shape64 D 0.73 < L_func 0.75 < **acc 0.77**）→ 无法确立独立价值；子检查（固定 metric+width 只变 lr）**符号翻转**（grid64 eucl,w64 = −1.00×3 而 cosi,w64 = +0.87/+0.87/+1.00）。诊断显示配置间信号（6.83/7.63）大于配置内噪声（1.68/2.03），故失败非噪声淹没所致。**净结论：检测理论判决裕度是第 6 个被证伪的区分度候选读数**。**正面副产品**：shape64 上"训练难度在功能空间可读"得到强证据（D@10 与达门轮数 3/3 种子 rho ≤ −0.68），但**最佳读数是最廉价的 acc@10** —— 这解释了 v1.0 用 acc 信号即可工作、而 v1.2 必须加宽度归一（acc 排难度、排不了代价）。caveat：达门轮数定义含 acc 条件，J5 的靶子对 acc 有利；但即使排除，D 也未优于 L_func，结论不变 |
| 合成图像 | CNN（grid64 + shape64，共 20 单元） | CP-E 表征精度天花板（零训练探针，**轴②的"筛子"位置**） | **把"区分度"从预测器改放到筛子位置**：检验它能否给出"**该表征上任何分类器都达不到的精度上界**"。`ceiling_code` = 码上 Bayes 最优（多数标签规则，train 计数估 p(y\|c)）、`ceiling_1nn = 1−err_1nn/2`（借 1-NN ≤ 2×Bayes 界）、`ceiling_5nn`（点估计）；直接读已有 opt_demo 检查点，**零训练**。**E0 健全性 20/20 通过**（标签置换后塌到 ≤0.018 ≈ 1/64）→ 估计器实现无误。**E1a 不通过**（grid64 9/11、shape64 7/9：4 个单元 ceiling 略低于实测 acc，幅度 ≤0.018）；**归因已用对照确定**：α∈{1,0.1,0.01,0.001,0} 逐位相同 → **不是平滑偏差**，而只统计"训练样本 ≥3 的码"时违反消失（ceiling 回到 1.0000）→ 是**稀疏码的有限样本偏差**（3%/7% 测试样本落在 <3 训练样本的码上）。**E1b 20/20 通过**（pre-VQ 特征上界 ≥ 码上界）。**E2 gap≈0**（中位 0.000 / −0.002，极差 −0.018~+0.051）→ 天花板紧到无余量、训练头已达码上最优。**E3 不可判定**（未过门单元仅 grid64 1 个：cfg19 kt128 acc=0.865 → ceiling=0.916<0.95 命中 1/1，方向正确但样本 <3，按教训 3 不得记为负结果）。**E4 两任务不一致**（grid64 ceiling 0.868 vs `H(Z_t)` 0.887 → 无独立价值；shape64 0.900 vs 0.583 → 貌似更优）→ 不能确立独立价值。**两条决定性发现**：① `ceiling_1nn≈1.000` 在全部 20 单元成立（1-NN 误差 = 0）→ **pre-VQ 特征里 64 类完全可分，表征根本不是约束**，故本就没有可测的天花板；② 人为压缩码本 m 的对照（k-means 归并码字）显示 **ceiling 几乎完全贴着 `m/64` 走**（m=1:0.010 → 16:0.207 → 32:0.450 → 64:0.718 → 128:0.926 → 256:0.968；参考 m/64 = 0.016/0.25/0.50/1.0/1.0/1.0）→ **饥饿区该读数只是容量界（轴①）的重新表述，充分区恒为 1**。**净结论：轴②的"筛选用法"与"预测用法"同样判负，且原因是原理性的——充分区无信息、饥饿区与轴①冗余**（第 7 个被证伪的读数；前 6 个是"不可测/无预测力"，这个是"**可测但退化/冗余**"） |
| 合成图像 | CNN（grid64 61 + shape64 42 单元） | CP-F 信号-冗余分解 + 扰动稳定性（零训练，**轴②的"第三量"方案**） | **CP-E 证明只用 `(Z, training labels)` 的量必被夹在 [Fano 下界, 1] 且两端退化，故本探针引入第三量**：①**标注 nuisance**（生成器已知模板 → 逐样本精确恢复亮度增益 `g_hat=<x,T(y)>/<T,T>` 与噪声残差 `r_hat`），用岭回归探针测 `r2_br/r2_nz` → `q_nuis = i_sig/(i_sig+i_nuis)`；②**扰动阶梯**（由 `g_hat·T(y)` 重建干净图，走噪声 σ∈{0.15…1.5} 与增益 η∈{0…0.5}）→ `stab_drop`、`stab_br_drop`。**三条结构发现**：**(1) 表征确实编码 nuisance** —— `r2_br` = 0.47–0.96（grid64）/ 0.59–0.89（shape64），亮度增益几乎可线性读出（**直接测到了"冗余"**，正是容量界看不见的量）；**(2) 噪声残差探针数值病态** —— `r_hat` 方差仅 6.6e-3，60/61 与 42/42 单元的 \|R²\|≤0.05（一例 −2.15）→ **判为不可用（测量失败，非负结果）**，故 `i_nuis` 实际由 `r2_br` 主导，并行报 `q_br`（与 `q_nuis` 逐单元差 <0.005）；**(3) 亮度脆弱性是容量相关** —— `stab_br_drop` 在充分层 ~0.000、在饥饿的 kt=128 层 0.15–0.29，跨层 rho = −0.912/−0.905 → **BatchNorm 式增益不变性恰在码本饥饿时破裂**（两任务一致，但作为容量代理而非质量读数）。**判据**：F0b 通过×2（随机初始化落机会水平 0.0203）；**F1 通过×2×4（四个读数在两任务上"配置间 > 种子间"，记录中唯一一次"疑似质量读数"连过两次功效关）**；F2/F3 混合（`q_nuis` grid64 过 F2+F3 而 shape64 变成容量代理 rho=+0.929；`stab_drop` 两任务都过 F2 而 shape64 变成 acc 代理 rho=+0.890）；**F4 不通过（跨任务不一致）→ 不允许泛化宣称**。**结论：CP-F 未通过，记为"混合结果"而非干净负结果**——与前 7 个失败性质不同（非空洞、非冗余，而是**独立性随任务翻转**）。**三处实现修正（均属"数学上不可用"并同时报出原判定）**：(a) F0a 原用双侧 `\|R²_perm\|≤0.01`，但负 R² 意为"比预测均值更差"= 无泄漏，泄漏检验必须单侧（四个越界值 −0.89/−0.90/−0.33/−0.15 系判据 bug）；(b) 修正后阈值 0.01 仍**低于统计量自身的零假设噪声底**（1/√1920=0.023，122 次检验的最大值天然达 ~2.7σ）→ 校准后（3σ=0.069）两任务通过，无可检出泄漏，原阈值系标定错误；(c) `r2_nz` 保留存档但不进判定，`q_br` 并行报告。**结算它需要第三个任务（未决项 5），不是调阈值** |
| 真实数据 | MLP（MNIST + 注入增益 nuisance） | CP-G 第三任务（结算 CP-F 的 F4） | **换掉"同族性"再跑一遍完全相同的读数与判据**：MNIST-10 + **构造注入**的逐图亮度增益（模板不再需要，方法可迁移），主干换成普通 MLP（无卷积、**无 BatchNorm**）、类数 10。**前置门先过**（参考配置 median acc = 0.9525 ≥ 0.95；8ep 时 0.9423 未过 → **加预算到 20ep，未降门槛**）。**F0a 通过**（置换目标单侧 R²=+0.0143 < 3σ=0.0474）；**F1 通过 ×3**（配置间 0.1122 vs 种子间 0.0100 等）；**F2 不通过**（`q_br` rho=**−0.960**、`stab_drop` rho=**−0.927** → 两者都判为容量代理）；F3 通过（−0.781 / −0.598）；**F4 不通过** —— `q_br` 在 grid64 过 F2（+0.079）而在 shape64（+0.929）与本任务（−0.960）都不过，**跨任务不一致是系统性的、不是两任务同族的偶然**。**结论：轴② 连"冗余"这个位置一并关闭**。**两条结构发现**：**① nuisance 编码随容量增长，这正是比值无法摆脱容量的原因** —— `r2_br` 随 d 单调升（0.41→0.90，d 8→128）而信号侧饱和（`i_sig` 1.68→2.05 ≈ ln10=2.30），故 `q_br` 必然是容量的单调函数（这是第三个**有原理的**关闭，前两个见 CP-E）；**② 标量输入增益对 ReLU MLP 是代数上不可见的**（fc1(g·x)=g·fc1(x)，ReLU(g·a)=g·ReLU(a)，fc2(g·h)=g·fc2(h) → argmax 不变，实测 `stab_br_drop` ∈ [−0.003, +0.002]）→ 该读数在本任务**判为退化**；这也反过来精化 CP-F 发现③：那里同时有 BN 与 VQ 码本，饥饿层的增益敏感性必来自**码本归属在增益下改变**，而非网络的线性代数。**一处阈值标定错误如实记账**：F0b 原设 0.1±0.02，随机初始化实测 0.1350 → 判据不过，但该阈值过紧（随机特征+随机头仍保留少量 MNIST 信号），其**目的**（区分"学到/没学到"）明确满足（0.135 vs 0.88–0.96）；按项目规则**同时报出原判定与标定说明**，不静默放宽 |

**优化器 v1–v1.2 收官（2026-09-23）**：三层 reward（L0 G0 硬约束 / L1 达门代价 / L2 早窗 L_func）+ η=3 的 SH 剪枝（rung 10/20/40），空间 metric×width×lr 共 18 配置。关键杠杆是**「穷举一次 → 离线精确重放任意方案」**（地基自检 25/25 逐位一致实测确认）。主实验结论：① **P2 当时判"剪枝无价值"，后经口径修订推翻**——原始轮数口径不看每轮宽度代价，且 v1.0 的 acc 信号下 SH/单保真/随机搜索全部选错（瓶颈是信号不是预算）；② **P5 墙钟不可信**——同配置同代码仅因测量时段差 4×，主口径按预注册条款修订为达门轮数；③ P3 L0 硬约束在"选择"上有真实贡献；④ P4 有误伤。两轮信号迭代：**v1.1** 达门轮数优先（同预算 regret 2→0；留出种子 0-2 选、3-7 评估）；**v1.2** 加宽度 FLOPs 因子（拦下 4× 更贵竞争者）。三版冠军一致 cfg1（euclid, w16, lr1e-3）。适用边界：全部结论在 grid64 单任务；P11/P12 属链路/非盲测。

**优化器 v2–v2.3 收官 + 口径定稿（2026-09-23）**：空间自 v2 起加 teacher 码本 K_t 轴（{128,256,512,1024,2048}，共 90 配置）。第三次口径修订（定稿）：墙钟 → 原始达门轮数 → **归一成本 = 达门轮数 × (conv(w) + K·d)**。口径一改判定就翻：P2 从"不支持"变成**支持——剪枝有价值**（SH regret 3.93 vs 随机搜索 15.82）。**v2/v2.3 K_t 轴（容量贪婪）**：**Q1 被证伪**（K_t=128 层可行 9/18，真结构是码本×度量交互）；**G1/R1 被证伪**（K_t=2048 码本门 6.10 未排除任何配置，18/18 可行）；**但贪婪自限于 K_t=1024**（层内最优归一成本 128:7.0→256:6.1→512:4.2→**1024:3.4**→2048:5.0 触底回升），机制 = 门限"多要轮数" + VQ 项线性增长。结论：门限不排除配置，而是通过成本构成软上界。另记两处自我修正（(12) 补成本项、范围过窄的过度概括；(14) "H 与门限同步上升"被证伪，真规律是 H@acc过门≈常数 4.2–4.9）。项目定位收窄：「预测 cliff 可定位性」主线已穷尽判死，工具定位为测量工具 + 适用域说明。

**v3.0 第二任务泛化验证（2026-09-25，shape64）**：先踩到数据管线 bug（`make_data` 位置传参把种子当成 `sigma_pix`，首轮 53 单元作废删除；特征签名=失败水平只依赖种子 → 诊断管线而非动力学）。修复后 216 单元：**T1 核心支持**（v1.2 归一信号 regret=0 跨任务成立；对照 v1.1 原始轮数 41.25、v1.0 acc 2.95）；**T2 支持**（拐点 K_t=1024 跨任务复现，三层数值与 grid64 逐位相同）；**T4 不支持**（L_func@10 秩相关 |r|<0.3）；**T3 部分**（256 锚点层 18/18 复现；码本×度量交互因 128 层未采集不可判定）；G1/G3/R1 同向复现。harness 修订三处（限层重放池按实际采集集、未采集层改判"不可判定"、T1–T4 报告落地）。方法论教训：**跨层比较"层内最优成本"时各层种子集必须一致**。地基自检：补做真训 ep20 与前缀重放比对 3/3 一致（覆盖"已过门"分支）。

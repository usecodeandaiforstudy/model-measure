# 三轴框架：理论、立场与存活结论

> 定位：把"神经网络 = 信号处理系统"压缩归档为一份文档 —— 理论框架（含 A-001 修正）、作者立场，以及本项目收口（2026-09-25，v0.2 → optimizer v3.0）之后仍然存活的结论。
> 分工：`README.md` 是对外入口（产品线）；本文只回答**框架级问题** —— 三条轴各自成不成立、为什么、以及哪些话不能说。文中对 `viewpoint.md` / `research-summary.md` 的交叉引用，指的就是本文所取代的那两份文档（两份已退休，内容并入本文）。

## 0. 原始判断与 2026-10 修正

作者判断（2026-09 对话要点）：

- 神经网络本质上是一个**信号处理系统**：给定输入，映射到输出；所谓学习，本质上是**找到合适的映射** —— 把输入对应到合适的输出。
- 最重要的性质有三条：1. **信息容量** —— 网络能容纳多少信息；2. **信息区分度** —— 不同输入是否可区分（原文："训练的本质是让不同输入在相空间中的位置更可区分"）；3. **训练难度** —— 怎样建立正确的输入输出映射。
- 这三条不是三个独立的精度指标，而是**同一件事的三个侧面**：容量决定"装不装得下"，区分度决定"摆得整不整齐"，训练难度决定"摆进去要花多少代价"。
- 后期补充限定：目标不是预测与指导网络设计，而是**任务↔网络的对应性判断** —— 给定一个任务和一个网络，判断配不配。

> **2026-10 修正（A-001，作者本人）**：原表述中的"相空间"统一修正为**输出空间** —— 训练是在输出空间中为每个不同输入找到合适的位置；内部状态只是把输入送往输出空间的**通道**，性质只定义在输出边界上。这不是措辞之争：它一次性解释了轴②为何关闭（能摆开多少本来就是信息通过量问题）、轴③为何跨任务不可比（输出空间的坐标系由任务定义）、以及参数/表征空间读数为何全灭（它们量的是"这一次用哪套参数实现的"，不是映射本身 —— 等价解漂移）。以下一律使用修正后的表述。

## 1. 判定速览

| 轴 | 判定 | 一句话原因 |
| --- | --- | --- |
| ① 信息容量 | **成立** —— 唯一拿到硬判据的轴，也是唯一跨任务的轴 | Fano/DPI 给的是必要条件：能证"装不下"（`log K < R_IB`）；在合成硬墙任务上下界实测紧致可定位 |
| ② 输出空间区分度 | **关闭** —— 三个位置全部关闭，各有原理，非试错失败（共试过 8 个读数） | 区分度不是独立自由度：要么退化为容量界的换皮，要么按构造就是容量函数 |
| ③ 训练难度 | **成立，但仅任务内可比** | 归一成本口径（达门轮数×宽度因子）任务内可排序；跨任务无共同标尺 |

**三条轴是对的，但可操作性不对称**：① 能产出硬判据，③ 能在同一任务内排序，② 经检验不能作为独立判据存在。产物是一个轻量 PyTorch 工具，用**信息论容量**回答三个本来没有答案的问题：**训练时** —— 容量够不够、有没有过拟合（容量诊断）；**部署时** —— 量化到多少比特还不丢任务信息（量化下界）；**蒸馏时** —— 学生该多小（蒸馏容量下界）；外加一个副产品：**训练在环的配置优化器**（把"容量-成本"目标变成可剪枝的搜索问题）。因此本项目定位为**测量工具 + 明说适用域**；原先更高的目标 —— "蒸馏前预测 cliff（容量墙）可不可定位" —— 已被 CP1 → CP3 补测① 的一连串负结果彻底判死。

## 2. 轴①：信息容量 —— 成立

**机制**：在表征 `T` 之后插入 `VQBottleneck(d=64, n_codes=K)`（不改损失、不改优化器），按最近邻量化到码本、梯度直通，从码本熵 `H(Z)` 与码本大小 `K` 的关系读出容量。诊断量：`H(Z)`（无偏 O(1) 估计，不用脆弱的 MINE）；`K_min = ceil(exp(Fano(1-acc, C)))`，任务信息量对应的最小容量；`ρ = K*/K_min`，容量盈余比（**仅诊断**）。

**成立的原因**：信息论不等式（Fano、DPI）是**必要条件**；必要条件的正确使用方向是**否证** —— 容量低于任务所需 ⇒ 确定装不下。这个方向在本项目上反复验证成立：

- log K 紧致性（P1/C1/T1 三线）：`H(Z)` 与 `ln K` 近似 1:1 增长 —— MLP 斜率 0.95、CNN 0.88、小 Transformer 0.88；Transformer 残差流修正让 FFN 内的窄瓶颈不再锁死（+0.519）。
- 任务侧需求可算：`R_IB` 由参照模型的错误率经 Fano 反解，`K_min = ceil(e^{R_IB})`；`log K < R_IB` ⇒ DPI + Fano **在数学上禁止**完成该任务 —— 这是**可证排除**，与"训练算法能不能找到解"的任何假设无关。
- Fano 下界 `K_min` 在硬墙任务上可定位，蒸馏实测 `K*` 与 `K_min` 的经验比 1.7–3.0 四格一致（CP3）；grid64 上 `K*=96` 三个种子完全相同（中位比 1.71，Feature B v3）。
- 拓扑修正：纯串行 → `min_capacity_serial`；有旁路 → `sum_capacity_parallel`（每条支路"各算各的"）。这是硬前提，用错会严重低估：同一组串行瓶颈（min = 1.79 nats），加一条并行支路后精度 0.103 → 0.876（P4）。P2：无旁路时取 min 成立；P3：容量匹配的收敛更快。
- 量化：Feature A PASS（合成线性任务，由量化下界 `q_min` 预测 cliff）；QAT 三臂对照 —— QAT-vq PASS 3/3，伪影档 `q=5/6` 从 0.45–0.56 恢复到 0.98+（移除量 0.477），QAT-uniform 只移除 0.006 ⇒ **全部增益来自量化参数学习，而非分类器自适应**；在容量墙 `q=3` 三臂全崩（DPI+Fano 的数学墙不是 QAT 能救的）。
- 泛化：C1/C2/C4（CIFAR-10 + CNN：紧致性 / 宽度天花板 / Fisher 维）PASS；T1/T2（小 Transformer：log K 紧致性 / 残差流）斜率 0.88。

**边界**：同一条不等式不能反向用 —— "装得下"推不出"会好"。它只是必要条件，且 `R_IB` 是**事后**量（需要参照模型），所以只能事后校准，不能事先指导"该建多大"。轴①成立的全部内容都在"下界与筛除"这一侧。它出错的方向是安全的：判"可行"最多只是"必要条件满足"，判"不可行"是确定结论。

**适用域**：轴①的全部验证在**小规模/合成任务**（MNIST/CIFAR 级以下）；无真实大模型验证。拓扑必须先判定。cliff（容量墙）定位只需一个条件 —— 任务信息量足以形成墙（`log K < H(Y)` 构成禁区）。原先的第二个条件"学生的表征簇结构清晰（CNN 卷积特征不满足）"**作废**：C3 v3 的负结果被 CP3 复核改判为**预算伪影**（教师双重欠训：`acc=0.961` 刚过门但码本已塌到 `H(Z_t)=4.18 ≈ ln 64`，256 个码只用了约 65 个；学生在整个网格上都欠训，`g(256)=0.145` 是假平台）；在 40ep 标定预算下同一任务的 cliff 清晰可定位，且 CP3 四格（MLP/CNN × euclid/cosine）全部可定位，`K*/K_min ≈ 1.7–3.0`。C3-CIFAR 的判死仍然成立，但原因已被细化（见 §10.2）：不是"10 类任务没有墙" —— 强参照模型（acc 0.77–0.80）下 Fano 排除可测（R1a/R1b 3/3，`K_min=4`）—— 而是**"有墙无 cliff"**：容量-精度映射弥散、建不起平台、`K*` 无法定位 —— 排除可测、定位不可测。

## 3. 轴②：区分度 —— 关闭（有原理的关闭）

轴②经历了三次位置迁移 —— 预测器 → 筛子 → "第三量" —— 每次都有明确假设、预注册判据和干净的负结果；共试过 8 个读数。**三次关闭不是"还没找到对的读数"，而是逐层逼出了同一个原理。**

### 3.1 预测器位置：6 个候选读数全灭

试图在表征/参数空间找静态读数，预测训练难度或 cliff 可定位性：

1. 表征簇几何 silhouette（CP1）—— 该预测（蒸馏前预测 cliff 可不可定位）被 **REFUTED**（留出臂未能验证）；
2. 码本余量剂量-反应 `m = H(Z_t) − ln C`（CP2）—— **误判**：快跑与全跑一致地失败；`K_t=96` 误判；`K_t=128` 在全跑下 `m` 升入灰区、被自动判为 UNDECIDABLE，快跑下则误判；正对照 `K_t=256` 命中；
3. `I(Z;Y)` 端点（CP3 补测①）—— 无分辨力：N=64000 独立估计 + Miller–Madow，两 CNN 格**精确相等 4.033±0.000** 而 ρ 差 50%；
4. 率失真拐点 `K_99`（CP3 补测①）—— 逐档重合；
5. `L_info` / `L_sys`（Fisher-Rao 弧长，CP3 补测①）—— **等价解漂移污染参数空间**：同格不同种子弧长差 3.86×（s2），梯度窗位移极差 117 ≫ 格间差 64；
6. 检测理论判决裕度 `d′`（CP-D，两任务各 54 单元）—— 第 6 个被证伪者。J0 训练复用自检 PASS（54/54 逐位相同，复训与主跑同源）；J1 sanity PASS（`frac(m≤0) = 1−acc` 逐位相同）；J3 方向 + 可分性 **FAIL**（grid64 连方向也不过，rho −0.29/−0.00/−0.23；shape64 方向过 −0.73/−0.68/−0.82、3/3 种子 ≤ −0.5，但可分性两任务 0/3）；J4 跨任务两任务皆不过（诚实的负结果）；J5 独立价值**不一致**（grid64 D 0.23 > L_func 0.16 > acc 0.06；shape64 D 0.73 < L_func 0.75 < **acc 0.77**）。旁证：固定 metric+width、只变 lr 的子检验**变号**（grid64 `eucl,w64` = −1.00×3 而 `cosi,w64` = +0.87/+0.87/+1.00；shape64 `eucl,w16` = −1.00/0.00/+0.87）；配置间信号（6.83/7.63）高于配置内噪声（1.68/2.03），所以失败**不是**被噪声淹没。stage 0 修掉两个退化（都属"度量不可用"，不是"结果不满意"）：概率差定义在 1/4 的单元上 `MAD = 0` ⇒ 度量无定义（D 爆到 5e6）⇒ 改用 log-odds；`min_c(class median)` 是 64 个类中位数的极值、跨种子乱跳（同配置 −1.000 / +0.985）⇒ 改用 5% 分位。定义块：`m(x) = logit(y_true) − max_{j≠y_true} logit(j)`；`S_low = Q_5%(m)`，`noise = MAD(m)`，`D = S_low / noise`；固定窗 e0 = 10，目标 = 达门轮数。CP-D 是本项目第一个**干净零结果**（定义固定、预算充足、数据完整、J0/J1 双重自检通过、判据先于数据）。方法学附注：达门轮数含 acc 条件（G0 = acc≥0.95 且 H≥阈值），所以 `acc@10` 与它的高相关带有**定义性成分** —— 但即便撇开这点，D 相对 L_func 也没有多出任何能力（0.73 vs 0.75）。

**教训**：等价解漂移 ⇒ 参数空间读数在原理上不可比；**USABLE** 的读数必须在**功能/预测空间**。`L_func`（累计预测翻转）是唯一实测 USABLE 的读数 —— 它量在预测空间，等价解漂移不贡献 —— 但它是**过程量**，不是静态区分度。

### 3.2 筛子位置（CP-E）：两端退化（第 7 个读数）

把区分度改放到"筛子"位置 —— 表征上的精度天花板（任何分类器都达不到的上界），在既有 checkpoint 上**零训练**探测（20 单元）：`ceiling_code` = 码上 Bayes 最优（多数标签规则，`p(y|c)` 由训练计数估计）；`ceiling_1nn = 1 − err_1nn/2`（经 1-NN ≤ 2×Bayes 界）。E0 sanity（标签置换必须塌到 ~1/64）**20/20 PASS**（≤0.018）⇒ 估计器实现正确；E1a 有效性 **FAIL**（grid64 9/11、shape64 7/9，违反幅度 ≤0.018）—— 归因来自对照：α∈{1,0.1,0.01,0.001,0} 的结果逐位相同 ⇒ 不是平滑偏置，而是**稀疏码的有限样本偏置**（只统计"训练样本 ≥3"的码时违反消失、天花板回到 1.0000；3%/7% 的测试样本落在训练样本 <3 的码上）；按预注册纪律，该判据按实测记为不过，修正版只作诊断；E1b 特征上界 ≥ 码上界 20/20 PASS；E2 紧致性 gap ≈ 0（中位 0.000/−0.002）⇒ 无松弛；E3 筛除力 **UNDECIDABLE**（只有 1 个单元不过门，命中 1/1，样本 <3，不得记为负结果）；E4 与 `H(Z_t)` 的仲裁两任务不一致（grid64 无价值 / shape64 看似更好）。两个决定性发现（结论不依赖 E1a）：`ceiling_1nn ≈ 1.000` 在 20 个单元上全部成立（1-NN 误差 = 0）⇒ 64 类在特征空间完全可分，表征根本不是约束，E2/E4 的空洞是**任务属性**而非估计器缺陷；码本压缩对照（k-means 把码字归并为 m 桶，预测先于数据）：天花板 m=1:0.010 → 16:0.207 → 32:0.450 → 64:0.718 → 128:0.926 → 256:0.968，对照 `m/64` = 0.016/0.25/0.50/1.0/1.0/1.0。

**原理**：充分区天花板恒 ≈1、无分辨力；饥饿区天花板 ≡ 容量界 `m/64`。在这个位置上"区分度"没有给出任何超出容量界的信息 —— **是容量界的换皮**。这属于"可测但退化/冗余"，与前六个失败（"不可测 / 无预测力"）性质不同。

### 3.3 "第三量"位置（CP-F / CP-G）：按构造就是容量函数

CP-F 引入标注 nuisance + 扰动阶梯（两条路线合用，零训练，103 单元），试图分离"信号编码"与"冗余编码"：标注 nuisance —— 生成模板已知，逐样本精确恢复亮度增益 `g_hat=<x,T(y)>/<T,T>` 与噪声残差 `r_hat`，用岭回归探针 `t → g_hat/r_hat` 得 `r2_br/r2_nz`，`q_nuis = i_sig/(i_sig+i_nuis)`；扰动阶梯 —— 由 `g_hat·T(y)` 重建干净图像并扫噪声 σ∈{0.15…1.5} 与增益 η∈{0…0.5} → `stab_drop`、`stab_br_drop`。三个结构性发现（独立于任何判据）：(1) 表征确实编码 nuisance —— `r2_br` = 0.47–0.96（grid64）/ 0.59–0.89（shape64），这是本项目第一次直接测到"冗余"（花在任务不需要的变化上的比特），也正是容量界看不到的量；(2) 噪声残差探针数值病态 —— `r_hat` 方差只有 6.6e-3，60/61 与 42/42 个单元落在 |R²|≤0.05（一例 −2.15）⇒ 判为**不可用**（测量失败，不是负结果），于是 `i_nuis` 实际由 `r2_br` 主导，`q_br` 平行报告（逐单元与 `q_nuis` 之差 <0.005）；(3) 亮度脆弱性与容量相关 —— `stab_br_drop` 在充分层约 0.000、在饥饿的 kt=128 层为 0.15–0.29，跨层 rho = −0.912/−0.905 ⇒ BatchNorm 式增益不变性恰在码本饥饿时失效，但它是**容量代理**而非质量读数。

CP-F 判词：F0b sanity（随机初始化应落在随机水平）**PASS ×2**（acc 0.0203 / 阶梯末端 0.0203 vs 1/64=0.0156）；**F1 功效**（配置间 > 种子间）**PASS ×2 ×4** —— 四个读数在两任务上全过（如 `q_nuis` 0.097 vs 0.035 / 0.179 vs 0.025），这是本项目第一次有"疑似质量读数"连续两次过硬功效关；F2 非容量代理 **MIXED**（`q_nuis/q_br` grid64 +0.079 PASS / shape64 **+0.929 判为容量代理**；`stab_drop` +0.261/+0.262 两任务皆过；`stab_br_drop` −0.912/−0.905 两任务皆判容量代理）；F3 非 acc 代理 **MIXED**（`q_nuis/q_br` −0.110/+0.043 皆过；`stab_drop` +0.258 PASS / **+0.890 FAIL**；`stab_br_drop` −0.776/−0.383 皆过）；F4 跨任务一致性 **FAIL**（`q_nuis` 在 F2 上翻转、`stab_drop` 在 F3 上翻转）⇒ **不允许任何泛化声明**。净结论：CP-F 失败，记为 **MIXED 结果**而非干净负结果 —— 不是空洞、不是冗余，而是"独立性随任务翻转"；`q_nuis` 在 grid64 上过 F1+F2+F3，`stab_drop` 在两任务上过 F2；要结案需要第三个任务，而不是调阈值。三处实现修正（全属"数学上不可用"类，且都同时报告原判词）：(a) F0a 的双侧 `|R²_perm|≤0.01` 是判据 bug —— 负 R² 意味着无泄漏，泄漏检验必须单侧，四个越界值 −0.89/−0.90/−0.33/−0.15 收敛为单侧最大 +0.021/+0.031；(b) 即便修正后，0.01 这个阈值仍低于统计量自身的零假设噪声底（1/√1920=0.023；122 次检验的最大值自然到 ~2.7σ）⇒ 按 3σ=0.069 标定后两任务皆过 = 无可检出泄漏，原阈值是标定错误；(c) `r2_nz` 留档，不进判词。

CP-G（第三任务 mnist_gain_mlp：真实 MNIST-10 数据 + 合成注入的逐图亮度增益 + 纯 MLP —— 无卷积、无 BatchNorm、10 类、类数不同；不再需要生成模板，方法可迁移；读数与判据逐字不动）：先过前置门 —— 参照配置中位 acc **0.9525** ≥ 0.95（8ep 时 0.9423 不过 ⇒ **加预算到 20ep，不降阈值**）；第一版带 VQ 的设计被前置门拦下（d=128/K=512 20ep 只有 0.746；d=256/K=2048 反而回到 0.705；利用率 45%→34% —— **约束是训练预算，不是 d/K**），且**未评估任何判据**。判词：F0a 泄漏检验 PASS（单侧 +0.0143 < 3σ=0.0474）；F0b **原判词 FAIL**（0.1350 vs 0.1±0.02）→ **阈值标定错误**（过紧；其目的已达成：0.135 vs 训练后的 0.88–0.96），如实记录、不静默放宽；**F1 功效 PASS ×3**（`q_br` 0.1122 vs 0.0100；`stab_drop` 0.0382 vs 0.0052）；**F2 FAIL**（`q_br` rho=**−0.960**、`stab_drop` rho=**−0.927**，皆判容量代理）；F3 PASS（−0.781/−0.598）；**F4 FAIL** —— `q_br` 只在三个任务之一（grid64）上过 F2；在 shape64 和本任务上都不过。净结论：**轴②连同"冗余"位置一起关闭**；CP-F 的 F4 失败不是两个任务同族的偶然，而是系统性的。两个结构性发现：(1) **nuisance 编码随容量增长 —— 正是比值逃不出容量的原因**：`r2_br` 随 d 单调升（0.41→0.90），而信号侧饱和（`i_sig` 1.68→2.05 ≈ ln10=2.30），更宽的一层同时编码更多增益和更多类别，所以 `q_br = i_sig/(i_sig+i_nuis)` **按构造**就是容量的单调函数 —— 这是轴②的第三个有原理的关闭（CP-E 死于两端退化，这一条死于其中一项随容量增长）；(2) 标量输入增益对 ReLU MLP 代数不可见（`fc1(g·x)=g·fc1(x)`、`ReLU(g·a)=g·ReLU(a)`、`fc2(g·h)=g·fc2(h)` ⇒ argmax 不变；实测 `stab_br_drop` ∈ [−0.003,+0.002]，判为退化）⇒ 增益不变性探针不得用于评估任何 ReLU MLP —— 读数恒为 0；这也细化了 CP-F 发现③（那里同时有 BN 和 VQ 码本，所以饥饿层的增益敏感性来自**增益下的码本归属变化**，不是网络的线性代数）。

**原理**：瓶颈越大，装下的 nuisance 越多 —— "冗余编码比"按构造就是容量的函数。这不是实验失败，是**该量的定义性退化**。

### 3.4 关闭判词与限定语

> 区分度作为**独立于容量的第三轴**不存在：在信息有分辨力的每一个位置上，它要么恒饱和（充分区）、要么是容量界的直接函数（饥饿区）、要么随容量单调增长（nuisance 编码）。轴②的全部有效内容已被轴①吸收 —— 区分度**可测，但不能作为独立判据**。

**2026-09-30 域外补充（CP-H 轴②，CIFAR-10 非饱和区，见 `docs/cifar10-anchor.md` §3）**：上述关闭判词是在**饱和区**内建立的（grid64 的 1-NN 误差 = 0）。在真实非饱和任务上，S1 前提成立（教师中位 err_1nn=0.228、silhouette=0.187 —— 关闭原理首次在其原始适用域之外被检验）、S2 ×4 全过（i_plug 0.92 / silhouette 0.64 / separation 0.68 / d′ 0.60；读数在 knee 窗口携带质量信息，rho(acc) 0.60–0.92，与合成饱和区的"恒常数、无分辨力"对照）。但 H_indep 未确立（无容量无关读数，rho(logK) 0.64–0.82，S3 全灰区），H_proxy 也未证实（无纯代理）。**关闭判词需要一条限定语：在非饱和区，区分度与容量高度纠缠，独立轴仍未发现，但"纯代理"的强形式也不成立 —— 关闭原理的弱形式存活。** 仲裁观察（事后，非预注册）：没有读数优于 H(Z)/acc。

## 4. 轴③：训练难度 —— 成立但有范围

- **读数**：归一成本 = 达门轮数 × (conv(w) + K·d)，其中 `conv(w)=1728w²+2560w`，外加早窗 `L_func`。门是 G0 双门（`L0` 硬约束：`acc ≥ 0.95` 且 `H(Z_t) ≥ 0.8·ln K_t`）；`L1` 主目标 = 达门的代价；`L2` 廉价信号 = 早窗 `L_func@10`。
- **任务内成立**：该读数 + 早窗 L_func 可对训练配置做代价排序；v1.2 归一信号在 grid64 与 shape64 两任务上 regret = 0；在归一信号上做 Successive Halving（`η=3`）在同预算下 regret 达到 0。
- **跨任务不可比**：达门轮数依赖任务的门，不同任务的门不在同一标尺上；换任务后 `L_func` 不再与成本单调（T4：逐种子 `Spearman(L_func@10, 归一成本)` = 0.19 / 0.24 / 0.18，`|r| < 0.3` ⇒ **T4 NO SUPPORT**，其秩相关形式按事后操作化如实记录）；`K_t` 拐点处的剖面形状两任务不同（512 档 4.2 vs 6.3）；shape64 的绝对成本系统性高于 grid64，但这不代表"更难"，只代表口径不同。
- **最佳读数是最廉价的**：CP-D 的 J5 仲裁显示，排序训练难度时 `acc@10`（0.77）≥ `L_func`（0.75）> D（0.73）—— 新指标必须过"是否优于最廉价既有读数"这一仲裁关。值得单独记录的正面副产品：shape64 上"**训练难度在函数空间可读**"获得强证据 —— `D@10` 对达门轮数在 3/3 种子上 rho ≤ −0.68，早窗 e0 = 2 时符号相同；问题在于最好的读数是**最廉价的那个 `acc@10`**（0.77），而不是任何"新"指标。这也顺带解释了为什么 optimizer v1.0 用 acc 信号能work、v1.2 必须加宽度归一 —— **acc 能排难度，但排不了成本**。
- **作者接受的两条（数据驱动）修正**：(i) "相空间"必须钉在函数/预测空间，不能是参数空间 —— 参数空间的一切读数都被等价解漂移污染，而预测空间的读数成立；(ii) "变得更可区分"不是持续过程 —— **12 个单元在最后一个 epoch 全部 `flip = 0`**（预测在末轮完全冻结；翻转只发生在训练中段），这正是**早窗读数（前 2–5 epoch）反而比全集更干净**的原因（它们在过程还在发生时采样），也说明"训练难度"是**非平稳**量：不同时间点采到的不是同一件东西。
- **L_func 作为读数**：早窗 `L_func` 是 ρ（容量适配度）的第一个有效读数，只花完整训练的 **1/8–1/20**（前 2 epoch 已零重叠、前 5 epoch 留 4× 余量；8 种子、零重叠、跨 4 组探针稳健）；它与 ρ 解耦、被重定位为"拟合成本"（一个结构-任务对的训练重组成本），ρ 降级为诊断量（多档剂量）。但 `L_func@10` 的宽度单调性**两任务皆 FAIL**（grid64 13.0/12.3/17.8；shape64 13.7/19.9/19.4）⇒ 按预注册，两任务的剪枝都退回纯 `acc@rung` 定义，且在第二任务上 L_func 只作为记录量、不进剪枝信号。
- **宽度成本让口径变得要紧**：w32/w64 每 epoch 贵 3.83×/14.98×，而 wall clock 跨跑不可比（同配置、同代码仅因测量时间窗就差 4× —— cfg1 达门轮数最少却按 wall clock 排到第 #11 ⇒ 第一版的 `P5` REFUTED）。成本定义改过三次、每次都翻转判词：v1.0 `acc@rung` 3.93；v1.1 原始达门轮数 9.22（**单看更差** —— 宽度偏置是空间扩张后才暴露的）；v1.2 达门轮数 × 宽度归一 **0**。

**优化器证据（grid64 = 任务一；shape64 = 任务二，换编码模态：3 条带 × 4 个形状 → 64 类，与 grid64 的唯一差别是编码模态，判别必须发生在卷积通道上）。** 空间：`metric × width × lr`（18）+ 教师码本 `K_t ∈ {128,256,512,1024,2048}` → **共 90 个配置**；shape64：72 配置 × 3 种子 = **216 单元**（`--layers 256,512,1024,2048`，80ep 预算）。关键杠杆：**"跑一遍 → 任意方案离线精确重放"** —— 早停是确定性的，所以最深档单元的曲线与浅档逐位同源，一次采集即可用零额外训练重放任意剪枝键、种子数或基线方案；该等价性由**基础自检**实测确认（grid64 25/25 逐位相同；shape64 3/3 一致，范围有限：只覆盖"已过门"分支），不是假设。

- grid64：**P2 SUPPORT**（剪枝有价值：SH regret 3.93 vs 等预算随机搜索 15.82）；**P3 SUPPORT**（`L0` 硬约束对"选"有实际贡献，2 vs 4 epoch）；P4 collateral damage（gold 在 rung2/rung3 被剪）；P6 平局（多保真度无增益）。
- 容量贪婪：`Q1` **REFUTED**（`K_t=128` 层可行 9/18；真实结构是**码本 × metric 交互**：可行的全是 cosine，不可行的全是 euclid）；`G1`/`R1` 也 **REFUTED**（`K_t=2048` 的 6.10 码本门**一个配置都没排除**）。但贪婪在 `K_t=1024` 自限：层内最优归一成本 `128:7.0 → 256:6.1 → 512:4.2 → 1024:3.4 → 2048:5.0`（**在 1024 触底反弹**）；机制：门"要求更多 epoch"（层内最优 epoch 数反弹 3→4）**+** VQ 项线性增长（2048 时达到 `conv(w16)` 的 +27%）。
- shape64：**T1 信号泛化（核心）SUPPORT** —— v1.2 regret = 0，最终选择 = gold = `cfg56(euclid,w16,lr3e-3,kt1024)`；对照：v1.0 acc 信号 regret 2.95，v1.1 原始 epoch 数 regret 41.25（它取 w64，宽度成本未归一）⇒ **宽度归一仍是决定性的一项**。**T2 贪婪自限复现：SUPPORT** —— 层内最优 `256:6.1 → 512:6.3 → 1024:3.4 → 2048:5.0`，拐点在 1024；其中三层（256/1024/2048）与 grid64 逐位相同（6.1 / 3.4 / 5.0），只有 512 层不同（4.2 vs 6.3）；机制相同，最优配置的 epoch 数反弹 3→4 且 VQ 租金为 +11.9%。**T3 G0 边界复现：PARTIAL** —— `K_t=256` 锚点层可行 18/18（复现）；**码本 × metric 交互 UNDECIDABLE**（在 grid64 上该交互出现在 `K_t=128` 层，本轮未采集）。**T4：NO SUPPORT**（见上）。同向伴随复现：**G1** —— 门依旧不咬人，2048 层 **54/54 单元过** `H(Z_t) ≥ 6.10`（实测 6.11–6.52）；**R1** —— 仍不排除任何配置（18/18）；**G3** —— 信号没有取最大 `K_t`：贪婪被**成本**而不是门拦住。
- 净结论：optimizer v1.2 的信号设计，以及 v2 的两条主张 —— "门只形成软成本上界"与"贪婪有内在自限" —— 在编码模态切换后的第二任务上都泛化；唯一不泛化的是 L_func（T4），而它本来就从未进入剪枝信号。门不排除配置；在成本口径下贪婪有内在最优，空间不需要人为设限。

**与架构研究的接口（A-002，2026-10）**："大映射 → 路由函数 × 一族局部函数"的分解（QKV 的内容寻址、MoE 的参数路由）**不改变容量下界，改变的是达到上界的代价** —— 干扰降低、可达性提高。故**架构差异是轴③的内容**：任何"架构 A 优于架构 B"的断言都只在同任务、同预算口径下成立。由此也回答了"内部结构只是通道，架构演进为何仍值得研究" —— 架构不决定"能不能"（那是轴①），决定"能不能被找到、代价多大"（轴③）。

## 5. 总判词：测量成立，预测判死

| | 测量（事后） | 预测（事前） |
| --- | --- | --- |
| 状态 | **成立** | **判死** |
| 依据 | 容量下界、训练成本、cliff 位置都是可测的，且跨任务逐位复现 | 全部 6+ 个预测读数被证伪；轴②三次位置迁移均退回容量 |

分界的原理：信息论给**必要条件**（下界），必要条件擅长否证（"装不下"）、不擅长证立（"装得下就会好"）。本项目把这条分界从口号变成了逐实验的实证边界。墙与 `K*` 读数保持**协议相对**（依赖训练配方、预算、学生族与种子），引用时必须连同测量条件；可证排除不依赖这些。

## 6. 对"任务↔网络对应性判断"的回答

用三轴检验"任务 T 与网络 N 配不配"：

- **能判**：容量不够（`H(Y)` 或 `R_IB` 超过瓶颈上界）⇒ 确定不配。这是硬判断，已有多个任务实证，且出错的方向安全（判"可行"最多只是"必要条件满足"）。
- **不能判**：容量够的两者谁更配、配了之后训练顺不顺、cliff 可不可定位 —— 这些需要轴②/轴③的预测能力，而轴②已关闭、轴③跨任务不可比。
- 即：对应性判断的**否定半**成立，**肯定半与排序半**不成立。

两个判定为可行的具体问题（属必要条件型问题而非预测）：**(a) 指导网络蒸馏** —— 判断给定学生能否完成教师的任务；关键理由是蒸馏正是"事后量"这一限制不构成障碍的场景（教师天然存在，`R_IB` 可零额外成本测得）；实测经验裕度 `K*/K_min ≈ 1.7–3.0`（grid64 单任务 1.71、有效剂量 9/9、CP3 四格 1.7–3.0 一致）。**(b) 用"任务复杂度"判断网络能否完成该任务** —— `H(Y) = ln C`（类数熵，粗粒化复杂度：**纯任务属性，设计时已知**，但只是上界，忽略类间相关）；`R_IB`（任务**实际需要**的信息：可操作定义，但是**下界估计**，需要参照模型）；gap `R_IB − log K`（可行性缺口，判断的直接依据）。要保住的方向性：因为 `R_IB` 是下界，"低于它 ⇒ 不可行"可靠，而"高于它 ⇒ 可行"不成立（只是必要条件满足）。

```
R_IB = H(Y) − h(err_teacher) − err_teacher · ln(C−1)   # Fano, using the teacher's error rate
K_min = ceil(e^{R_IB})                                  # the student's capacity lower bound
criterion: log K_student < R_IB  ⇒ definitely cannot do it (no need to train)
```

**项目能答与不能答**：能答容量够不够、量化下界、蒸馏下界、容量上界（拓扑必须先判定），以及同任务内配置的成本排序；不能答用任何信息论/几何/检测量预测性能或 cliff 可定位性。分界线清楚：**凡是问"至少需要多少"的都能答；凡是问"这样够不够好 / 会不会更好"的都不能答。**

**对外要守的表述边界**：只讲下界、只讲筛除、不承诺预测；全部证据在合成/小规模任务上（合成 grid64/shape64 + MNIST/CIFAR 演示），真实大模型任务未验证；`R_IB` 是**事后量**（需要参照模型）⇒ 只能事后校准，不能事先指导"该建多大"；前提条件**按判断分级** —— **排除判词零训练**（只需参照模型的测试精度 + 候选结构的容量上界），墙几何预检零训练（参照模型一次前向），只有"测某个网络的容量"与"定位 `K*`"需要插瓶颈并重训（诊断脚手架）；三条前提缺一不可 —— **任务有墙**、**拓扑判定正确**、**参照模型足够强**（否则 `R_IB` 被低估 ⇒ 假的"可行"）。

闭环于 2026-09-30 完成（CP-H / PA1；判定报告在 `docs/cifar10-anchor.md` §2）：蒸馏判据（`K_min` + 落差曲线）在合成硬墙任务上成立，并且 (1) 在真实任务上得到验证 —— **排除能力迁移**（R1a/R1b 3/3、R4 −0.98×3：低于 `K_min=4` 的学生被数学碾碎，可操作的筛除）、**cliff 定位不迁移**（平台 1/3，唯一 `K*=128`，裕度 32× —— 是合成 1.7–3.0 的十倍以上），使用边界因此细化为"判不配的那一半在真实任务上成立；定位最小可行学生的那一半仍专属硬墙任务"；(2) 任务复杂度量可操作 —— `K_min` 按教师 acc 分段量子化（acc < 0.715 ⇒ `K_min≤3` 退化；0.715–0.807 ⇒ `K_min=4`；>0.807 ⇒ ≥5），0.78 的门标定依据正是"筛掉退化区"；10 类任务的退化不是"没有墙"，而是**"有墙无 cliff"** —— 排除可测、定位不可测；(3) 可交付用法成立：**判断任务与网络配不配，并在不配时给出可证排除理由**（Fano 排除在真实任务上 3/3）。对原判断的两条修正（已接受）："10 类任务没有墙 ⇒ 工具失效" —— 错：墙存在，只是 cliff 定位失败；"`K_t=128` 最终无效" —— 错（PA1 阶梯证明 120ep 达门、200ep 全 1.0）：那是轴③的"薄边际 + 高代价"，不是容量压力区的最终判词。两者都是**预算/口径伪影**，再次印证**负结果本身也可能是错的**。

## 7. 为什么学不到"怎么搭才好"

**"装不装得下"是关于所有网络的数学不等式（可证、可排除）；"怎么搭才好"是关于某一条具体训练路径的经验事实（只能事后测）。** "怎么搭才好"要成为可学对象，需要四条必要条件同时成立；本项目逐条否证：

| 必要条件 | 状态 | 实测证据 |
| --- | --- | --- |
| (a) 目标在决策时已存在 | **不满足** —— 成本/质量是**过程的属性** | 一例：`H(Z)=2.80 > R_IB=2.30` 说明装得下，但 acc 只有 **0.746** |
| (b) 目标与可观测量一一对应 | **不满足** —— **等价解**让同一个函数有无穷多种参数实现 | 同格弧长差 3.86×、极差 117 ≫ 格间差 64，而预测完全相同 |
| (c) 规律跨任务稳定 | **不满足** —— 实测跨任务翻转 | 达门轮数不能跨任务；换任务后 `L_func` 不再单调；`q_br` 只在三个任务之一上过容量无关关 |
| (d) 目标函数已知 | **不满足** —— "好"是**人选的框架** | 成本口径**改过三次，每次都翻转判词** |

| 框架级条件（源文件 §7） | 状态 | 出处 |
| --- | --- | --- |
| 存在跨配置可比的静态读数 | ✗ 参数空间被等价解漂移污染 | CP3 补测① |
| 存在独立于容量的区分度信号 | ✗ 三位置全关 | §3 |
| 存在跨任务可比的难度标尺 | ✗ 仅任务内可比 | §4 |
| 预测信号优于最廉价既有读数 | ✗ 全部不敌 acc@rung | CP-D J5 |

四条全不满足 ⇒ 不是"数据不够"或"模型不对"，而是**该学习对象的信号基础不存在**。更尖锐地说：**唯一被证明有效的读数是"过程量"**（`L_func`），而过程量必须**先跑一遍**才能测 —— 它不是算出来的，是记录下来的。强化学习路线（用本项目做环境训策略调超参）同理：它的价值只可能在**跨任务策略迁移**，而 (c) 已被实测否定；RL 需要**决策时可评估的 reward**，而 (a) 不成立；reward 若取预测量则已被证伪，若取成本量则退化为已解决的排序问题（bandit/SH 的地盘 —— 同预算下 SH 的 regret 可以达到 0）。因此两条不再主张的方向：用信息论**预测网络性能 / 预测 cliff 可定位性**（这条路已穷尽 —— 轴②的 6 个读数），以及用强化学习**训练调参策略来学怎么搭网络**（理由如上，比"空间会被穷尽"更根本）。

## 8. 负结果与元教训

### 8.1 被自身推翻的负结果

- **C3 v3**：首判是诚实的负结果（在连续卷积表征上 VQ 压缩代价随 `log K` 平滑衰减、没有 cliff、`K*` 定位 0/3）；CP3 复核改判为预算伪影（数字见 §2）。
- **`K_t=128` 层"最终无效"**：归档的平台（40ep 0.73–0.83；80ep 重标定后仍 0.83–0.90，增量收益递减）被 **PA1 阶梯（2026-09-30）推翻** —— GPU 复跑，全种子 120ep 达门、200ep 全 1.0000 ⇒ 平台是轨迹/预算伪影，它是轴③的"薄边际 + 高代价"（约 120ep 可达）。
- **grid64 的 P2 一度读作"剪枝没有价值"**：后被口径修订推翻 —— 原始 epoch 计数口径只看 epoch，没看 w32/w64 每 epoch 贵 3.83×/14.98×，于是随机搜索靠多样性命中宽配置，显得"好"。
- **三条预测 Q1 / G1 / R1 REFUTED**：Q1 假设 `K_t=128` 层"几乎全不可行"（实际 9/18）；G1/R1 假设 6.10 的门必须排除 2048 层（实际 18/18 全过）。共同错误：**把"训练早停时读到的值"当成"能力上限"**。
- **shape64 轮的工程问题（全部修复并归档）**：首轮数据管线 bug —— `make_data` 把 `seed` 当位置参数传进了 `sigma_pix`，实际跑成了"σ 扫描"（s0=σ0 无噪声，全部过门；s1/s2=σ1.0/2.0 噪声淹没信号），且三个种子共用同一份噪声实现 ⇒ **首轮 53 个单元全部作废**（改为 `make_data(n, seed=seed)`）；层受限重放池未收窄（`--layers` 只采集 54 个配置，但重放用 `pool=None` 在 90 上算，`n_keep = 90//3^(r+1)` ⇒ `η=3` 剪枝比被隐式放松到 ~1.8；加 `collect_pool()` 修复）；"没数据"被读成"不可行"（`Q1`/`G3` 把未采集的 `K_t=128`/`2048` 层报成"0/18 不可行 / 已被挡住"；统一为 UNDECIDABLE，并新增 `blocked` 标记区分"有数据但 0 可行"）；预注册 ≠ 已实现（v3.0 的 T1–T4 只存在于 docstring 预注册，报告代码根本没输出；T4 的秩相关形式是事后操作化，已声明）；基础自检被整体跳过（首次 `--layers` 只训最深档、无在线浅档对照 ⇒ **未通过**；后补真正训练的 ep20 单元对照：3/3 一致，范围有限，只覆盖"已过门"分支，同一代码路径在 grid64 上是 25/25）。

**元教训**：`P2` 的"负结果"来自**定义错误**；C3 v3 的来自**预算伪影**；`Q1`/`G1`/`R1` 的"正结论"来自**把缺失数据读成负结果**。**每个判词都必须能回答：这条读数是在什么定义、什么预算、什么数据完整度下成立的？** 三者任一错，判词方向就可能翻转。反过来，CP-D 是本项目第一个**"干净零结果"**（定义固定、预算充足、数据完整、J0/J1 双重自检通过、判据先于数据 —— 指标就是不管用）。四种情形合起来说明：**判负之前必须排除前三种；只有活下来的负结果才可信。**

### 8.2 方法论教训（可迁移）

1. **定义先于结论** —— 成本定义改过三次，每次都改变判词；wall clock **跨跑不可比**（同配置、同代码仅因测量时间窗就差 4×）；改定义时**信号、主目标与敏感性检查**必须一起对齐，否则跨定义比较必然得出错误结论。
2. **跨组比较时各组的种子集必须完全相同** —— 种子数不同是污染，不是"数据更多更好"：单种子探边界让 T2 读出与 3 种子**相反**的结论（1 种子剖面 `6.1/6.3/4.5/3.8` ⇒ 无拐点；3 种子 `6.1/6.3/3.4/5.0` ⇒ 有拐点），因为层内最优是 18 个配置中位数的最小值，而 `median-of-3` 在 3 与 4 epoch 间跳变。
3. **"没数据" ≠ "不可行"** —— 没有守卫时 `0/18` 会被读成"整层不可行"，把未采集数据写成负结果；判定层必须显式区分三态：未采集（UNDECIDABLE）/ 已采集但 0 可行（硬排除）/ 有可行配置。
4. **缩减空间的实验必须在实际采集集上重算预算** —— 当 `--layers` 限定层数时，`n_keep`、名义预算与基线采样都必须相应收窄，否则剪枝比被隐式放松（`η=3` → ~1.8）、等预算比较被扭曲。
5. **小样本探边界只能回答定性问题** —— 单种子能回答"这层可不可行"，但回答不了需要细排序的拐点位置；探边界之前先确定它最多能支撑什么级别的结论。
6. **写进 docstring 的预注册 ≠ 判据已实现** —— 必须检查报告代码是否真的输出该判据。
7. **多种子失败的形态本身就是诊断信号** —— 若"失败程度只与种子有关、与所有超参无关"，先查**数据管线**而不是优化动力学（位置参数 bug 不报错，数据统计量看起来完全正常）。
8. **数据类函数的关键字参数必须显式传**（`seed=seed`）—— 位置传参在签名中间夹着默认参数时会静默错位。
9. **信号质量比预算更重要** —— 剪枝信号与目标定义错位时，剪枝表现**比随机搜索还差**。
10. **离线重放是省算力的杠杆，但必须先经测量验证**（基础自检）；否则整套结论都建立在一个未验证的等价性上。
11. **自检本身要防"平凡为真"** —— promotion-copy 产生的记录按构造与浅档逐位相同，拿它们比较是平凡为真，不计入。
12. **新指标必须过"是否优于最廉价既有读数"这一关（仲裁判据），否则它不该存在** —— CP-D 的 J5 正是为此设的：d′ 在 shape64 上确实与训练难度强相关（rho ≤ −0.68），但**同一窗口里 `acc@10`（0.77）与 `L_func@10`（0.75）都不比它差**；**"相关"不等于"有用"；有用 = 比别人便宜且比别人多信息。**
13. **指标工程必须分级** —— 先在零训练/免费阶段查三件事（实现 sanity；退化，如 `MAD=0`/None/爆炸；跨种子稳定性），全部通过后再花算力做确认（CP-D 的 stage 0 免费抓到两个"数学上不可用"的定义）。
14. **换读数的语言能绕开饱和，但不自动买到有效性** —— CP1 → CP-D 就是"熵量饱和 ⇒ 换检测量"：方向对，结果仍是负；绕开一个病灶只解决"能不能读"，不解决"读到的有没有用"。
15. **把读数从"预测器"位置搬到"筛子"位置之前，先查两个端点** —— 充分区是否恒为常数（那它不携带信息）；饥饿区是否与既有界重合（那它是冗余）。CP-E 两头都占，这也是"换一个更好测的量"通常救不活已被判死的路线的原因。
16. **sanity 判据的阈值必须与统计量自身的零假设噪声底对齐** —— CP-F 的 F0a 原设 `|R²_perm|≤0.01`：一是误写成双侧，二是该阈值低于 `1/√n_test = 0.023` 的噪声底，而 ~122 次检验的最大值自然到 ~2.7σ。**修改判据必须能说出"为什么这在数学上不可用"，而不是"结果不满意"** —— 本项目全部 4 次判据修订（CP-D stage 0 两次、CP-F 的 F0a 阈值、CP-G 的 F0b 阈值）都按此标准记录，且每次都同时报告原判词。
17. **"功效"（能不能分辨）与"独立性"（是不是既有量的代理）是两道独立的关**，不能互相替代 —— CP-F 四个读数在两任务上都过了功效关，但独立性随任务翻转：**有分辨力的读数仍然可以是代理**。
18. **任务必须先过前置门；被门拦下的设计不得评估任何判据** —— CP-G 的 VQ 版在标定阶段就暴露"进不了已训练区"（d=128/K=512 20ep 只有 0.746；d=256/K=2048 反而回到 0.705，利用率 45%→34% ⇒ **约束是训练预算，不是架构**），此时 acc 与容量轴完全混淆，跑判据只会得到任务伪影；处理方式是**重新设计任务**（去掉 VQ、把容量轴换成宽度 d），而不是降阈值或改判据 —— 门本身是靠**加预算（8ep→20ep）**从 0.9423 抬到 0.9525 的。**判据只有在"任务成立"之后才有意义。**
19. **阈值必须与统计量的单位与噪声底对齐，"目的已达成"不能替代"阈值通过"** —— CP-G 的 F0b 设 0.1±0.02，随机初始化实测 0.1350 ⇒ 判据不过，尽管其目的（0.135 vs 训练后的 0.88–0.96）显然已达成；记录方式是原判词 + 标定说明一起报，**不是静默放宽**。

## 9. 适用域、禁区与如实边界

### 9.1 可用

- 容量诊断（`H(Z)` vs `ln K` 紧致性）。
- 部署量化比特下界（`q_min`），并可用 QAT 去掉 PTQ 标定伪影。
- 蒸馏容量下界（`K*` / `K_min`），前提是任务有硬墙且学生表征簇结构清晰（第二个条件已被 CP3/CP-H 作废，见 §2；存活的要求是硬墙）。
- 容量上界估计 —— **拓扑必须先判定**（串行 min / 有旁路 sum）。
- 训练配置的"成本"排序（归一成本口径），以及用早窗 `L_func` 读"拟合成本"。

### 9.2 不可用 / 不可靠

- 用 `ρ` 或任何静态读数**预测** cliff 可定位性（已判死）；以及用判决裕度 `d′`（或任何"区分度"读数）预测训练难度 —— 它确实相关（shape64 上 3/3 种子 rho ≤ −0.68），但不优于最廉价的 `acc@10`，且跨任务不可复现（CP-D，§3.1）。
- 把 `min_capacity_serial` 用到带 skip/residual/并行支路的网络上（会严重低估）。
- 假设"门能排除大码本配置" —— 门**不**排除，只通过成本形成软上界。
- 期待 `L_func` 换任务后仍与成本单调相关（T4 NO SUPPORT；宽度单调性两任务皆 FAIL）。
- 跨跑比较 wall clock；以及把"训练早停时读到的值"当成能力上限。
- 用"表征精度天花板"筛表征 —— 可测（E0 sanity 20/20）但退化：容量充分时恒为 1（20 个单元里 1-NN 误差都是 0），容量饥饿时等价于容量界 `m/64`（CP-E，§3.2）。**要判断"这个表征够不够"，直接用容量界（轴①），不要绕道精度天花板。**
- 把 CP-F 的读数当成已确立的质量指标 —— 它们在 grid64 上过 F1+F2+F3，但在 shape64 上 `q_nuis` 退化为容量代理（rho=+0.929）、`stab_drop` 退化为 acc 代理（rho=+0.890），F4 FAILS（CP-F，§3.3）；**它们不是 USABLE 判据**；把"信号/冗余比"（`q_nuis`/`q_br`）或扰动脆弱性当作容量无关的质量指标同样不行 —— 三个任务里 `q_br` 只有一个（grid64）过 F2，另两个都判为容量代理（shape64 +0.929、mnist_gain_mlp −0.960），机制是 **nuisance 编码随容量单调增长**（`r2_br` 随 d=8→128 从 0.41→0.90），所以该比值按构造依赖容量（CP-G，§3.3）。
- 用噪声残差 `r_hat` 做冗余探针 —— 该目标方差只有 6.6e-3，R² 数值病态（CP-F 结构性发现 2）。
- 用"增益不变性"探针评估任何带 ReLU 的 MLP —— 标量输入增益**代数不可见**（`fc1(g·x)=g·fc1(x)`、`ReLU` 正齐次、`fc2` 线性 ⇒ argmax 不变）；读数恒为 0，不携带信息（CP-G 结构性发现 2）。

### 9.3 如实边界（任何对外材料都必须附带）

1. 全部结论在**合成任务**上（合成 grid64 / shape64，CNN 主干），外加真实任务补记 CP-H（CIFAR-10）与 CP-G（MNIST）；无真实大模型任务验证。
2. 优化器线用 **3 个种子**。
3. **当信号与判据同构时，"命中"不构成独立验证** —— T1 与 P11 结论的一部分属联动/同义反复检查。
4. **基础自检范围有限** —— shape64 上只有 3 个对照点，且只覆盖"已过门"分支（grid64 是 25/25）。
5. `T4` 的秩相关形式是**事后操作化**（预注册只写了"逐种子可分"）。
6. `T3` 的码本 × metric 交互**UNDECIDABLE**（缺 `K_t=128` 层）。
7. `P8/P13` 留出泛化**UNDECIDABLE**（种子数 < 6）。
8. 达门轮数**不能跨任务比较**（宽度轴的成本结构两任务不同）。
9. 形状集与条带位置是设计选择（自由度）；形状面积与类别部分相关（9/3/3/5，存在部分捷径）。

## 10. CP-H / PA1 / PA4 / MOE 补记（2026-09-30）

> 完整判定报告在 `docs/cifar10-anchor.md`；预注册判据在 `experiments/cph_demo.py` 与 `experiments/pa1_demo.py` 的 docstring 中。全部工作在借用的 GPU 环境上完成，全程启用 relay 模式。

### 10.1 PA1（P-A1-3，判定 A）

预算阶梯（`K_t=128`，grid64 CNN-euclid，3 种子，40→200ep）：三个种子**在 120ep 全部达门、200ep 全为 1.0000** ⇒ **A-001 的推论通过了它最直接的检验** —— "容量够但摆不开"的案例不存在。`K_t=128` 是 A-002 的"薄边际 + 高代价"（轴③）：名义通道 ln 128 ≈ 4.85 nats 只比任务的墙 H(Y) ≈ 4.16 nats 宽 0.69 nats，可达性慢（~120ep vs 健康层的 ~40ep），但给足预算就能到 1.0。归档的 40/80ep"平台化"是**轨迹分叉伪影**，已被推翻（40ep 的 CPU 复跑与归档逐位相同、80ep 起分叉；GPU/CPU 轨迹从 epoch 1 就分叉 = 初始化族差异）。附带：160→200ep 时 `H(Z_t)` 从 4.63→4.32 而 acc→1.0 —— 后期压缩不是任务熵（clearance 0.48→0.16），正是关闭原理该有的样子。

### 10.2 CP-H 轴①（蒸馏排除向真实任务迁移）

CIFAR-10 + SmallCNN(width96)，教师 K=256/120ep/cosine，G0 阈值 0.78（按量子化 `K_min` 标定），网格 `K∈{2…256}` 共 13 档，3 种子：**R1a/R1b 3/3、R4 −0.98/−0.98/−0.99** —— Fano 排除判据在真实任务上**成立**，且可作为筛除规则运行（最小 gap 0.56–0.62）；教师的 `K_min=4` 对三个种子完全一致，与阈值量子化预测逐位吻合。**cliff 定位不迁移**：平台只建成 1/3（都卡在 0.02 容差的边缘），唯一 `K*=128` ⇒ **裕度 32×**（是合成 1.7–3.0 的十倍以上）；knee 在 K=8–32 上弥散；长尾衰减是 KD 目标的等预算成本（K=256 孪生学生 0.752 vs 教师 0.799）。**G0 2/3**（seed1 0.768，差 0.012，在一个噪声带内）：如实标记、阈值不动、**拒绝为过门而重掷**；seed 1 的 G0 以 **RESTRICTED** 入档。归档更正："10 类任务没有墙 ⇒ 工具失效"被细化为**"有墙（排除可测）无 cliff（定位不可测）"**。

### 10.3 CP-H 轴②与新方法论

关闭原理的域外检验见 §3.4（S1 前提成立：err_1nn=0.228、silhouette=0.187；S2 ×4 过；S3 全灰区，rho(logK) 0.64–0.82 ⇒ H_indep 未确立、H_proxy 未证实、弱形式存活）。本轮的新方法论：

- **`K_min` 是量子化的**：只要 acc 阈值落在某个量子化区间内即可（CP-H 0.78 阈值标定背后的推理链）；阈值应当按它筛掉的**区间**（退化的 `K_min`）来标定，而不是按噪声带里的某个具体值。
- **CUDA 训练的跑间方差是 ±0.03**（同种子、同配置）；VQ 死码重置的离散分支会放大 cuDNN 不确定性，所以标定数字本身带着这份噪声，而 checkpoint 重放不受影响（缓存单元只加载、绝不重训）。
- **relay 模式（默认）+ 加性网格扩展**（网格指纹只含基础网格，顶端扩展复用缓存）—— opt_demo v2 先例的推广。
- **遗留**：CP-H 轴② 的 14 点偏相关检验（rho(reading, acc | logK)）尚未做 —— 若要把灰区进一步仲裁，这是唯一可能的路径，但它需要更多单元；平台容差 0.02 在真实任务上处在边缘（0.025 vs 0.02），未来复跑应预注册一个按任务标定的容差；CP-H 全部结论都是单任务（CIFAR-10）+ 3 种子。

### 10.4 PA4（P-A1-4，判定 SUPPORT）与 A-003 的两条预测

- **命题**（A-003 已开条目，`docs/output-mapping-discreteness.md`）：cliff 锐度是**输出映射离散度**的函数、不是容量的属性；Fano 排除与离散度无关。
- **实验**：grid64 加一个弥散旋钮 δ∈{0,0.15,0.3,0.5}（与另一类模板 50/50 混合）× 3 种子，网格向下扩 {4,6} 共 10 档。
- **结果（Q1–Q3 全过）**：定位率 0.67→0.33→0.33→0.00、中位锐度 0.62→0.60→0.53→0.40 单调不增；`err_1nn` 0.000→0.114→0.223→0.390 单调升并干净地跨过 0.02；Q1 排除 12/12（`K_min` 随 δ 自动下移 35→6）；`wall_geometry_probe` 的 `DISCRETE_THRESHOLD=0.02` 由此**正式标定**。**协议修正记账**：首轮 δ=0.5 的"证否"其实是网格覆盖缺陷（`K_min` 低于网格底 8）被误读为违反；扩网格并把"不可判"与"违反"在判据里分开之后全部通过 —— **缺陷不是科学结论**。
- **理论意义**：CP-H 的"有墙无 cliff"由此获得**受控复现与机制归因**，并把"任务信息量足以形成墙"这个混同前提拆成 (a) 信息量 ⇒ 墙存在 / (b) 离散度 ⇒ cliff 锐利（**排除依赖 (a)、定位依赖 (b)**）。台账：P-A1-4 已对数据核验（**SUPPORT**）。
- **P-A3-1 已对数据核验（SUPPORT）**：在从未参与标定的 MNIST 上，探针预测弥散×3 且未测到有意义的 cliff（有意义的 `K*` 1/3 < 2/3）—— **探针首次前瞻性通过**；顺带确认 MNIST 是弥散墙任务。正向的离散墙臂仍待新数据。
- **P-A3-2 已对数据核验（PARTIAL SUPPORT，按原样记录）**：双定义 rho=+0.936（≥0.8 PASS）；以 0.02 为界两侧分类 53/54 一致 —— 唯一违反是未过 G0 的欠训 δ=0 教师（表征可分、读数欠训）⇒ **表征定义对欠训参照模型过于乐观**；部署纪律 = 先过 G0 前置检查再探。

### 10.5 MOE（两层容量读法验证，2026-09-30，route64 + oracle routing，6 种子）

- **任务/设计**：route64（8 簇 × 8 类，簇 = 块的列，路由信息恰为 ln8）；oracle routing（可由输入算出）+ 8 个专家（`VQ(K_e)`+head）；稠密对照 = `GridCNN(8·K_e)`。流量层界 = ln8 + lnK_e，存储层 = 8·lnK_e。
- **首轮预注册（T1a/T1b 锚在 Fano 墙 ln64）被 REFUTED**：ke=8（flow=4.16=墙）只到 0.57-0.60；cliff 实际在 ke=16/32。**根因 = 锚点选错**：稠密对照本身显示该任务族的实用墙在 K=256（K=64→0.39-0.60、K=128→0.69-0.90、K=256→0.999）—— Fano 下界把实用墙低估了 4×（与 CP-H 的 32× 裕度同源）。
- **重锚后续（新种子 5-7，F1 判据预注册）判定 SUPPORT**：F1a 2/2 可判种子（实测墙 256 → 预测 ke=32 → routed 1.000/0.999）；第三个种子没有可检出的稠密墙（其稠密学生 0.715），但 routed(32)=0.998 超过了它最强的稠密 —— 记为"不可判"，不是失败；**F1b 3/3**（每一档 routed ≥ dense(8·K_e)−0.05：等总码本下路由不更差、在高档更好 = A-002 §5.3 干扰机制的证据）。
- **工具包结论**：`conditional_capacity` 升级为 **VERIFIED（route64 任务族）** —— 存储层过 T2、流量层公式成立，且**锚点必须是实测的稠密墙，而不是 Fano 下界**；`kv_storage_capacity` 仍是 **CANDIDATE**（注意力任务超出范围，按原样记录）。

| 5 | ~~换**第三个任务**（换主干）~~ | **已完成（CP-G，§3.3）** | 用 MNIST + 注入 nuisance + 无 BN 的 MLP 去掉了同族性；结论与两任务假设相反（独立性随任务变化） |

**已关闭（不再遗留）**：三条轴各自都有了结论 —— ① 信息容量：**PASS**（唯一有硬判据的轴）；② 区分度：**判负**，三个位置全试过 —— 预测器用法 6 个读数（CP1/CP2/CP3 + 补测①/CP-D）、筛子用法 1 个读数（CP-E，§3.2，失败是有原理的：充分区无信息、饥饿区与轴①冗余）、"第三量"用法（CP-F/CP-G，§3.3，CP-F 为 **MIXED**，CP-G 为系统性关闭）；③ 训练难度：**PASS 但仅任务内可比**（归一成本口径 + 达门轮数）。**遗留项 5 已履行**，CP-F 的遗留也已结案：第三任务去掉了同族性（真实 MNIST 数据 + 注入 nuisance + 无 BN 的 MLP + 不同类数），`q_br` **仍然不过 F2**（rho=−0.960）⇒ 轴②连同"冗余"位置一起关闭，且关闭是**有原理的**（nuisance 编码随容量增长）；其结论与两任务假设相反 —— "读数独立性随任务变化"是系统性的。

**框架边界提醒**：A-001 的"输出边界"当前划在分类/token 输出上；latent reasoning 类路线（计算主体在连续隐空间、token 仅作渲染）若成立，边界定义需相应修正。
